# GEN-THINK 白猫思考通用动作族计划 v01

## 状态与边界

- 动作分类：`project_maintenance`；这是项目级共享可复用视觉资产，不属于任何单一期 episode workspace。
- 共享库路径：`leverage-video/src/shared/gen-think`。
- 资产族：`GEN-THINK`；一张母图加四张动作子图。
- 本动作族不绑定具体分镜、口播、episode 或时长；每个使用方只引用共享库中的获批版本。
- 五张 AI 源图获批前，不生成 1920×1080 派生图，不实现 Remotion 组件，不进入视频合成。
- BGM disabled；画面无旁白字幕、无文字、无伪文字、无问号、无灯泡、无对白框。

## 固定画面合同

- `16:9 landscape composition`；近 16:9 源图相对误差不超过 0.5%。
- 固定三分之四正面中景，完整显示单只白猫全身；猫位于画面略偏右，左侧保留柔和负空间。
- 背景为极简、温暖的冷压纸水彩空间：暖灰米白地面与轻淡靛蓝/赭石水彩晕染，无可读物件、无场景文字。
- 固定机位、裁切、透视、角色尺度、落脚基线、背景、光线、纸张纹理、色板与阴影。
- 风格：`loose-line-vivid-watercolor`；透明明亮水彩、露纸、松散断续黑褐干墨线。
- canonical v2 白猫实图作为每次生成的实际身份输入；SHA-256 `8d4d2fc6a4283cd05dfbb273d79cf1c13b062f79e2a5f945c1d5982a22a15c1f`。
- 白猫身份锁：宽圆脸、短胖蓬松象牙白身体、亮蓝大眼、明显书卷气眼圈、短卷白色苏格拉底胡、带暖灰环纹和暖褐尾尖的蓬松尾巴。
- 配饰锁：象牙色 himation 从解剖学右肩开始并带 muted-cobalt Greek-key 边；蓝色背带从解剖学左肩经前胸到解剖学右侧挎包；挎包保持右侧，配有橄榄叶扣、空白纸莎草和左胸猫头鹰挂件。
- P0 解剖锁：恰好两条前肢、两条后肢、四只爪；全身镜头中四肢与四爪都必须清楚、连贯、无重复。

## 五状态动作链

1. `GEN-THINK-master-v04`：白猫安静坐定；头部中性略抬，目光轻微向上；两只前爪均自然落地，两只后爪稳定支撑。`v01`–`v03` 均因四肢/四爪辨识度不足被内部 QA 拒绝。
2. `GEN-THINK-action-01-v01`：头部轻向一侧偏转，目光继续上移；四爪接触与重心保持稳定。
3. `GEN-THINK-action-02-v02`：一只前爪沿连续轨迹抬到下巴/胡须下缘，另一只前爪落地；两只后爪继续稳定支撑。`v01` 因缺少一只可辨认后爪被内部 QA 拒绝。
4. `GEN-THINK-action-03-v01`：保持同一只前爪与下巴接触；眉眼略收紧，躯干轻微前倾，重心仍落在落地前爪与两只后爪构成的支撑面内。
5. `GEN-THINK-action-04-v01`：目光略亮、头部稍抬、肩胸舒展；思考前爪沿原轨迹回到与母图完全相同的落地点，表现“想到一点方向”，不出现任何符号或文字。

## 独立生成与连续性

- 母图从 canonical v2 白猫实图加动作姿势参考生成；姿势参考只约束坐姿几何，不参与角色身份。
- 每张子图都必须从同一未改母图加 canonical v2 白猫实图独立编辑；禁止子图接子图。
- 只允许改变目标动作、视线、动作需要的表情，以及服饰/挎包/挂件随身体产生的必要物理跟随。
- 每一对相邻状态都检查朝向、重心、肢体轨迹、接触点、背带、右侧挎包、尾巴与因果顺序。
- 循环闭合顺序固定为 `master-v04 → action-01-v01 → action-02-v02 → action-03-v01 → action-04-v01 → master-v04`。
- `action-04 → master` 必须物理可达：四爪落点、身体中心、机位和背景完全注册，只允许眼神、眉眼与肩胸松紧发生小幅回落。
- 最终 Remotion 按真实 `durationInFrames` 重复上述闭环；首张母图直接完整显示，其后每个相邻状态边界均以 0.6 秒 `intra-shot-watercolor-bloom-v1` 进入（30 fps 下 18 帧）：彩墨落纸、炸开、沿纸纤维渗散并显图；不使用交叉淡化、morph、光流、插帧或未审批中间帧。
- 默认每个状态每次连续显示约 1.0–1.5 秒，任何状态连续不超过 2.5 秒；较长分镜只循环已批准五状态，不新增中间帧。

- 使用方只记录指向共享库精确版本与校验和的视觉层引用；若指定方案实质改变已批准分镜的语义或结构，则由该 episode 按自身工作流回退 Storyboard Review。
