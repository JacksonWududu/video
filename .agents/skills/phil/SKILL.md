# 哲学寓言 · Phil

> 不先说教，先讲故事。让答案在故事快收尾时自己浮现。

---

## 默认模式

用户说 `/phil` 或触发本 skill 时，执行以下流程：

### Step 1：选题

从哲学史中**任意挑一个**有深度的概念。偏好：

- 存在主义（尼采、克尔凯郭尔、萨特、加缪、海德格尔）
- 斯多葛（爱比克泰德、塞涅卡、马可·奥勒留）
- 道家（老子、庄子）
- 禅宗
- 古希腊（柏拉图、亚里士多德、赫拉克利特）
- 分析哲学碎片（维特根斯坦、语言游戏、可能世界）
- 或任何你认为有趣、值得讲透的概念

选题不重复常见鸡汤概念（比如"活在当下"已经说烂了就别选），挑有弹药味、有反直觉冲击力的。

如果用户指定了概念，直接用它。

### Step 2：写寓言

写一则原创寓言，长度 400—800 字中文。

硬约束：

- **不准在故事中点题**。不出现哲学术语，不出现哲学家名字，不写"这就像XX主义说的那样"。
- 人物、场景、情节全部为概念服务，但表面上只是一个普通的故事。
- 让读者在最后 10% 的位置才开始意识到"原来讲的是这个"。
- 结尾收在**一句不动声色但能刺穿整个故事的话**上——不要煽情，不要总结，不要"从此以后"。
- 寓言的语言要干净、冷静，像卡尔维诺或博尔赫斯的寓言，不像伊索寓言。不说教。

### Step 3：拆解

故事结束后，用分隔线 `---` 隔开，然后依次：

1. **点出哲学概念**：谁提出的、在什么著作/语境中、核心命题一句话。
2. **隐喻对照表**：列出故事中的关键元素，逐一映射到概念中的对应部分。格式：

```
| 故事元素 | 哲学内涵 |
|---|---|
| ... | ... |
```

3. **总结一段**：用大白话把这个概念说透——为什么这个概念重要、它回应了人的什么困惑、它在今天意味着什么。不超过 150 字。

## 品味守则

| 做 | 不做 |
|---|---|
| 故事冷、干净、有余味 | 鸡汤、煽情、强行金句 |
| 读者自己悟到最后一刻 | 开头就暗示"这是一个关于XX的寓言" |
| 概念讲透，一个就够了 | 堆砌多个概念 |
| 隐喻可以多层次解读 | 隐喻过于直白像说明书 |
| 拆解部分写得像好老师 | 拆解部分像百度百科 |
| 尊重读者智力 | 低估读者智力 |

核心原则：**好的寓言不是把概念翻译成故事，而是让故事本身就蕴含着概念的逻辑结构。** 寓言读完后即使不看拆解，读者也能感知到那个思想的形状——拆解只是帮读者确认"你感觉到的没错，就是它"。
