# 短视频 BGM 与音效匹配

## Overview

解决短视频创作者"找音乐难、卡点难、侵权怕"三大痛点。按情绪/节奏/赛道匹配免版权 BGM，提供卡点音效、热门原声追踪、商用风险扫描与自动卡点时间戳生成，全程给出可商用边界，避免侵权。

## 核心能力

### 1. BGM 匹配
按情绪（欢快/治愈/燃/悬疑/悲伤/科技感/复古/温情）、节奏（BPM）、赛道（口播/Vlog/带货/卡点/剧情）匹配免版权音乐，给出具体曲源与署名要求。匹配规则见 `references/mood-bpm-mapping.md`，免版权曲源见 `references/free-music-sources.md`。

### 2. 卡点音效
按卡点节奏推荐转场音效（whoosh/riser/swoosh）、提示音效（叮/pop/click）、鼓点（kick/snare）、环境音效。分类与来源见 `references/sound-effects-library.md`。

### 3. 热门原声追踪
追踪抖音/小红书/视频号/TikTok 等平台当前热门 BGM 与原声趋势，按热度增速（而非绝对值）判断，提示饱和度风险。追踪方法见 `references/trending-bgm-tracking.md`。

### 4. 商用风险扫描
给定音乐名/来源，判断授权类型（CC0/CC-BY/CC-NC/平台授权/订阅版权/公版）、是否需署名、商用边界、平台限制、录音版版权，输出风险等级（低/中/高）。判断框架见 `references/compliance-check.md`。

### 5. 自动卡点时间戳
给定视频时长与目标 BPM（可选段落标记），生成卡点时间戳清单：每4拍一个强卡点、每拍一个次卡点、段落切换必卡。调用 `scripts/beat_marker.py` 输出可直接导入剪映的时间戳表。BPM 检测可调用 `scripts/bpm_detector.py`（需 librosa，无则给替代方案）。

## 工作流决策树

按用户需求路由：

- "给视频配 BGM/背景音乐/什么音乐合适" → 能力1，读 `mood-bpm-mapping.md` + `free-music-sources.md`
- "卡点音效/转场音/叮的一声" → 能力2，读 `sound-effects-library.md`
- "现在流行什么 BGM/热门原声/抖音热歌" → 能力3，读 `trending-bgm-tracking.md`
- "这首歌能商用吗/会不会侵权/免版权吗" → 能力4，读 `compliance-check.md`
- "卡点标记/踩点时间/按 BPM 卡点" → 能力5，调 `beat_marker.py`
- `$run-knowledge-video` 已完成交付事务 → 读 `knowledge-video-post-delivery.md`，按该契约分析交付成片并给 3–5 首已核验候选
- 综合（既要配乐又要卡点）→ 先能力1匹配 BGM → 能力5生成卡点 → 能力2补音效 → 能力4确认商用边界

## 输出规范

- **BGM 推荐**：曲名 + 来源 + 授权类型 + 署名要求 + 适用赛道/情绪
- **卡点音效**：音效名 + 来源 + 使用时机
- **热门原声**：曲名 + 平台 + 热度增速 + 饱和度风险 + 商用边界
- **商用风险报告**：授权类型 + 署名要求 + 商用边界 + 平台限制 + 风险等级 + 替代建议
- **卡点时间戳**：时间戳（MM:SS.mmm）+ 卡点类型（强/弱/段落）+ 可导入剪映的格式

## Resources

## 重要约束

- 任何 BGM 推荐必须标注授权类型与商用边界，未确认授权前不承诺"可商用"
- 平台库音乐明确标注"仅限本平台"，跨平台分发务必切换 CC0/订阅源
- 公版曲需区分作品公版与演奏/录音版权
- 给出的曲源需真实存在，不确定时说明需用户自行核对
- 知识视频交付后模式必须实时核验官方曲目页和授权页；只能推荐，不得下载、混音、改动或重渲染已交付视频
