# 情绪 × 节奏 × 赛道匹配规则

## BPM 与情绪对应表

| 情绪 | BPM 区间 | 音色特征 |
|---|---|---|
| 欢快/活泼 | 100-130 | 明亮、跳跃、轻电子、尤克里里 |
| 治愈/温暖 | 70-95 | 钢琴、木吉他、舒缓、有呼吸感 |
| 燃/励志 | 120-145 | 强鼓点、推进感、弦乐铺底 |
| 悬疑/紧张 | 90-120 | 不规则节拍、低频、留白、不和谐音 |
| 悲伤/抒情 | 60-80 | 弦乐、钢琴、慢、留白多 |
| 科技感/未来 | 120-140 | 电子、合成器、机械感 |
| 复古/怀旧 | 100-120 | 放克、迪斯科、老唱片质感 |
| 温情/叙事 | 75-100 | 原声乐器、人声垫底、叙事感 |

## 赛道适配表

| 赛道 | 推荐 BPM | 配乐原则 |
|---|---|---|
| 口播/讲解 | 70-90 背景 | 人声为主、BGM 垫底不抢、轻柔纯音乐 |
| Vlog/生活 | 90-120 | 轻快/治愈、有呼吸感、段落分明 |
| 带货/种草 | 110-130 | 节奏明快、情绪向上、卡点明确 |
| 卡点/混剪 | 120-140 | 强节拍、BPM 稳定、段落分明 |
| 剧情/短剧 | 按情绪变速 | 情绪匹配、可变速、留白重要 |
| 美食/ASMR | 60-90 | 轻柔、不抢环境音、甚至无 BGM |
| 旅行/风景 | 80-110 | 治愈/大气、有画面感、推进感 |
| 知识/科普 | 90-110 轻背景 | 不抢讲解、稳定、循环友好 |
| 搞笑/反转 | 按情绪 | 前段轻快、反转处配反差音效 |

## 匹配决策流程

1. **定赛道**：先判断内容类型（口播/Vlog/带货/卡点/剧情…）
2. **定情绪**：内容想传达什么情绪（欢快/治愈/燃…）
3. **查 BPM 区间**：从上表取推荐区间
4. **从免版权曲源筛选**：见 `free-music-sources.md`，按情绪 + BPM 筛
5. **试听确认**：
   - 人声 or 纯音乐（口播避免有人声 BGM）
   - 是否抢主体（人声/讲解是否被淹没）
   - 段落是否适合卡点（4/8/16 小节有转折）

## 卡点视频选 BGM 专则

卡点/混剪对 BGM 要求最严：

- **BPM 稳定**：整曲误差 ≤ 2，避免现场版（BPM 漂移）
- **强节拍清晰**：kick/snare 明确，便于自动卡点
- **段落分明**：4/8/16 小节有明确转折，便于切镜
- **推荐区间 120-140**，新手从 120 起步
- **避免**：人声 BGM（抢卡点）、BPM 漂移、过长的 intro

## 情绪 + 赛道组合速查

| 内容场景 | 推荐组合 |
|---|---|
| 治愈系 Vlog | 治愈情绪 + 80 BPM + 钢琴/木吉他 |
| 燃向带货 | 燃情绪 + 130 BPM + 强鼓点 |
| 知识科普口播 | 温情 + 90 BPM 轻背景 + 纯音乐 |
| 卡点变装 | 科技感 + 128 BPM + 电子强节拍 |
| 悬疑剧情 | 悬疑 + 100 BPM + 不规则低频 |
| 美食 ASMR | 无 BGM 或治愈 + 70 BPM 极轻 |
