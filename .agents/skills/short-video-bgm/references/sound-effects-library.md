# 常用音效库

## 音效分类与用途

| 类别 | 常用音效 | 用途 |
|---|---|---|
| 转场 | whoosh / swoosh / riser / impact | 镜头切换、画面过渡、强冲击 |
| 提示 | 叮 / pop / click / bell | 重点标注、信息出现、UI 反馈 |
| 鼓点 | kick / snare / clap / hi-hat | 卡点、节奏强调、段落标记 |
| 环境 | 拍手 / 笑声 / 叮咚 / 键盘声 | 氛围、互动感、生活感 |
| UI | 滴答 / 哔 / 确认音 / 倒计时 | 教程、演示、数字呈现 |
| 情绪 | 笑声 / 惊叹 / 掌声 / 欢呼 | 反应、节奏点、情绪放大 |

## 免版权音效来源

- 海量音效、社区上传
- 授权：以 CC 协议为主，逐条查
- 商用：CC-BY 可（需署名），CC-BY-NC 不可
- 注意：务必看每条具体协议

### Mixkit Sound Effects (mixkit.co/free-sound-effects)
- 免费、可商用、不署名（多数）
- 分类清晰、质量高
- 适合短视频转场/提示音

### Pixabay Sound Effects (pixabay.com/sound-effects)
- CC0-like、不署名、可商用
- 更新快、分类全

### YouTube 音频库音效
- 免费可商用、部分需署名（标注）
- 官方可靠、分类全

### 剪映音效库
- 平台内授权、仅限抖音系发布
- 跨平台用需换源

## 卡点音效选用规则

| 卡点类型 | 推荐音效 | 效果 |
|---|---|---|
| 强卡点（每4拍/段落切换） | kick + impact | 重击感、画面定格 |
| 次卡点（每拍） | snare / hi-hat | 脆响、节奏推进 |
| 转场卡点（段落切） | whoosh + riser | 过渡感、蓄势 |
| 提示卡点（信息出现） | 叮 / pop | 标注感、吸引注意 |
| 情绪爆点 | 掌声 / 欢呼 / 冲击 | 情绪放大 |

## 音效叠加建议

- 转场段：whoosh（前）+ impact（落点），蓄势到落地
- 强卡点：kick（低频）+ snare（高频），低高叠加更饱满
- 提示点：单独叮，不叠加，保持清爽
- 避免音效过密：每秒不超过 1 个强音效，否则杂乱

## 注意

- Freesound 务必逐条查授权，NC 协议不可商用
- 平台库音效同样限本平台发布
- 音效虽短也可能有版权，谨慎使用
- 商用前核对：来源 + 授权 + 署名 + 平台限制
