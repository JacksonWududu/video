# 热门原声追踪方法

## 各平台追踪入口

### 抖音
- 剪映 → 热门音乐榜（按热度/增速排序）
- 抖音创作者服务中心 → 热点 BGM
- 抖音热歌榜（周榜/月榜）
- 创作者中心 → 音乐趋势

### 小红书
- 搜赛道关键词 → 看高频出现的 BGM
- 笔记互动数据反推热门原声（爆款笔记常用什么）
- 小红书音乐入口

### 视频号
- 微信指数 + 热门话题
- 视频号助手数据
- 搜关键词看高频原声

### TikTok
- TikTok Creative Center → Popular Sounds
- 按地区/赛道筛选

### Reels / YouTube Shorts
- 平台热门声音入口
- Shorts 热门音频榜

### B站
- 搜索榜 + 音乐区热门
- 热门视频 BGM 反查

## 趋势判断原则

1. **看增速不看绝对值**：热度上升快的（近 7 天新增用次高）比绝对值高的更值得追
2. **避免饱和**：已被用烂的 BGM（用次数极高）反而效果下降，平台可能降权
3. **赛道匹配**：热门 BGM 要与内容赛道契合，强行用不搭的热歌反而出戏
4. **时效性**：热门原声有周期，通常 2-4 周，越早用红利越大

## 饱和度判断

| 用次数/播放量 | 饱和度 | 建议 |
|---|---|---|
| 上升期（用次 < 平台均值） | 低 | 红利期，优先用 |
| 接近均值 | 中 | 可用，注意差异化 |
| 远超均值（爆款级） | 高 | 已饱和，效果递减 |
| 下降期 | 过气 | 不建议 |

## 风险提示（重点）

- **热门原声 ≠ 可商用**：平台内可用，商业项目/跨平台可能侵权
- **平台内授权仅限本平台**：抖音热歌拿到视频号用可能侵权
- **带货/广告需更谨慎**：商业用途授权要求更严，需取商业授权

## 追踪工作流建议

- **周更**：每周扫一次各平台榜，记录增速 Top5
- **建库**：把可用的免版权热门原声存入自己的 BGM 库（标注授权）
- **二创规避**：用热门原声的二创版本（变速/翻拍/翻唱自制）规避部分风险
- **备选**：始终备 3-5 首免版权 BGM 作为安全替代（CC0 库）

## 输出格式

```
曲名：XXX
平台：抖音 / 小红书 / 视频号 / TikTok...
热度增速：近7天 +XX%
饱和度：低 / 中 / 高
赛道适配：口播 / Vlog / 带货 / 卡点...
商用边界：平台内 / 可商用 / 需查授权
风险提示：XXX
```

## 重要约束

- 给出热门原声时务必标注商用边界，未确认授权不承诺可商用
- 跨平台分发提醒用户换 CC0/订阅源
- 商业用途（带货/广告）提醒取商业授权
