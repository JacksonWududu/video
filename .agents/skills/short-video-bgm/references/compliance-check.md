# 音乐商用合规判断框架

## 授权类型速查表

| 类型 | 商用 | 署名 | 演绎 | 平台限制 |
|---|---|---|---|---|
| CC0 | 可 | 不要求 | 可 | 无 |
| CC-BY | 可 | 必须 | 可 | 无 |
| CC-BY-SA | 可 | 必须 | 衍生须同协议 | 无 |
| CC-BY-NC | 不可商用 | 必须 | 可 | 无 |
| CC-BY-ND | 可 | 必须 | 不可演绎 | 无 |
| 平台授权（抖音/剪映库） | 仅本平台 | 否 | 可 | 跨平台侵权 |
| 订阅版权（Artlist 等） | 可（订阅期） | 否 | 可 | 无 |
| 公版（作品） | 可 | 否 | 可 | 无 |
| 公版演奏/录音 | 看录音权 | 看发行方 | - | - |

## 判断五步流程

1. **确认来源**：从哪个库/平台/作者来
2. **确认授权类型**：CC0 / CC-BY / 平台 / 订阅 / 公版
3. **确认署名要求**：是否必须署名作者、署名格式
4. **确认商用边界**：是否限非商用、是否限本平台、是否限用途
5. **确认录音版版权**：公版曲的演奏/录音是否仍保护（关键陷阱）

## 风险等级

- **低**：CC0（Pixabay/Mixkit）、订阅版权（Artlist/Epidemic，订阅期内）
- **中**：CC-BY（需署名）、平台内用平台库、YouTube 音频库（按标注）
- **高**：CC-BY-NC 商用、平台库音乐跨平台用、公版曲用受保护演奏版、热门原声跨平台

## 常见侵权坑（重点）

### 1. 平台库跨平台（最常见）
抖音/剪映音乐库的音乐，拿到小红书/视频号/B 站用 → 跨平台侵权。
平台内授权仅覆盖本平台，跨平台分发必须换 CC0 或订阅源。

### 2. 公版 ≠ 录音公版
贝多芬《致爱丽丝》作品公版，但某交响乐团 2010 年录音仍有录音权（保护至发行后 50 年）。
用公版曲需用"已确认公版的演奏版"或自制演奏。

### 3. 热门原声 ≠ 可商用
抖音热歌在平台内可用，但二次分发、商业项目、跨平台可能侵权。
"平台内能用"和"可商用"是两回事。

### 4. CC-BY-NC 误用
Freesound 上 NC 协议占比不低，商用即侵权。
下载前务必看每条的具体协议，CC-BY-NC 标记的不可商用。

### 5. 翻唱 / 改编
翻唱他人作品需机械复制权；改编需改编权。
自己演唱受版权保护的歌，仍需取得词曲授权。

### 6. AI 生成音乐
需确认训练数据授权，部分平台生成内容商用边界不清。
不同 AI 音乐工具的商用条款差异大，逐工具查。

## 输出风险报告格式

```
曲目：XXX
来源：XXX（库/平台/作者）
授权类型：CC0 / CC-BY / CC-BY-NC / 平台 / 订阅 / 公版
署名要求：否 / 是（署名文本：XXX）
商用边界：可 / 不可 / 限本平台 / 限非商用
平台限制：无 / 仅 XX 平台
录音版权：无 / 有（保护至 XX 年）
风险等级：低 / 中 / 高
替代建议：如高风险，推荐用 XX（CC0 替代源）
```

## 商用前安全清单

- [ ] 来源是 CC0 或订阅库？
- [ ] 如 CC-BY，署名是否到位（作者 + 链接）？
- [ ] 如平台库，是否仅本平台发布？
- [ ] 公版曲，演奏/录音版是否也公版？
- [ ] 跨平台分发，授权是否覆盖所有目标平台？
- [ ] 商业用途（带货/广告），授权是否覆盖商业场景？

全绿才可放心商用。任一存疑，先用 CC0 替代源。

## 高风险场景速判

| 场景 | 风险 | 处理 |
|---|---|---|
| 抖音音乐拿去视频号 | 高 | 换 CC0/订阅源 |
| Freesound NC 协议商用 | 高 | 换 CC-BY/CC0 |
| 公版曲 + 乐团录音 | 中高 | 确认录音公版或自制 |
| 热门原声做带货广告 | 高 | 取商业授权或换源 |
| Pixabay 音乐全平台分发 | 低 | 可直接用 |
| Artlist 订阅期内商用 | 低 | 可用，注意订阅状态 |
