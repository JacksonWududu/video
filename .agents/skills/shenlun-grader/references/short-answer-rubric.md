# 申论短题训练量表 v1

## 适用范围

用于归纳概括、综合分析、提出对策、贯彻执行或应用文、复合题。量表 ID 为 `diagnostic-short-v1`，仅供训练诊断；用户或官方细则有明确权重时，不使用本量表权重。

## 先抽取题干契约

阅读答案前，先记录：

- 作答对象与材料范围。
- 任务动词及其数量。
- 身份、受众、目的和文种。
- 字数、分项、格式等显式限制。
- 复合题的各子任务。

不得用惯常模板替代题干要求。题干只要求原因时，不得因答案没有对策而扣分；题干要求“提纲”时，不得机械要求完整公文格式。

将上述显式要求逐项写入 `prompt_requirements`，先生成 `requirements_lock`，再构建评分点；每项在报告中恰好对应一个非数值 check。

## 构建评分点

1. 给材料分段编号。
2. 拆出事实、判断、原因、影响、问题、措施和成效等证据单元。
3. 将表达同一核心意思的单元聚合为一个最小独立语义命题。同一主体为实现同一直接目的而连续采取的动作，原则上合为一项；并列主体、不同治理阶段或能够独立失分的关键机制才拆项。材料中的例子、数据和成效不得仅因句子独立便另立评分点。
4. 每个评分点写明对象、属性或动作、关系方向及不可省略的限定。
5. 每点记录精确材料字符区间；在阅读答案前把完整评分点图写入 case，并生成不含答案的 `criteria_lock`。锁定后不得修订；若确有材料解析错误，废弃本轮报告、重新锁定并从头批改，不得在对照答案后静默增删标准。

单个关键词不能独立构成评分点。答案虽出现关键词，若对象、方向、因果或立场错误，不得判为命中。

## 单点评定

- `full`：对象、关系与方向正确，表达足以独立成立，计 1 个单位。
- `partial`：方向基本正确，但缺少不可省略的信息，默认计 0.5 个单位。
- `duplicate`：与已命中命题相同，新增计分为 0。
- `unsupported`：材料、题干或允许的合理推导不支持，计 0；是否另扣分取决于已声明规则。
- `misdirected`：对象、层次或方向错误，计 0。
- `missing`：答案未涉及，计 0。
- `uncertain`：答案原句存在可定位的真实歧义，中心计 0.5 个单位，下限计 0、上限计 1，并扩大区间；没有答案证据时不得使用。

用户细则若规定不同的部分分比例，不得直接改写默认 `scoring_units`；只有细则能完整转成受支持的外部分项等级区间时才按外部量表数值评分，否则降为定性诊断。同一缺陷选一个最主要维度处理，不得以“内容不全”“语义不准”等不同名称重复扣分。

默认量表下，内容维度中的独立评分点等权。逐点诊断须穷尽固定后的评分点图，不能只列优点或缺点的样例。每个主要评分点的 `scoring_units.max` 为 1；`full/partial/missing/misdirected/uncertain` 的 `awarded` 依次为 `1/0.5/0/0/0.5`。重复表达和不占预期评分点的无材料内容记 `0/0`。计算式为：

`内容维度得分 = 内容维度满分 × 已得单位数 ÷ 评分点总数`

先以完整精度计算，再按四舍五入把内容维度实得分取至最接近的 0.5 分，并钳制在分项满分内。报告中心分直接等于各维度实得分之和，不另行调整残差。评分点如何聚合会明显改变结果且无法依据题干、材料解决时，改用 `limited` 与 `rule_ambiguity`，不得靠主观扩大区间继续给数值。

内容维度的定性等级按已得单位比例确定：`strong` 为 `[85%, 100%]`，`adequate` 为 `[70%, 85%)`，`developing` 为 `[45%, 70%)`，`weak` 为 `[0, 45%)`。

任务契合、组织和表达等非内容维度使用统一等级换算：`strong` 中心为满分的 `92.5%`，`adequate` 为 `77.5%`，`developing` 为 `57.5%`，`weak` 为 `22.5%`，再四舍五入至最接近的 0.5 分。必须先凭证据定级，再据等级换分。

总分区间不得任意填写。内容维度把 `uncertain` 的下限/上限计为 `0/1`，其他判定上下限等于中心单位；非内容维度采用等级比例区间。各维度先以完整精度求和；若逐维四舍五入后的中心总分位于原始边界外，先把边界扩展至包含中心分。总下限再向下取至 0.5 分、总上限向上取至 0.5 分。若宽度仍小于题目满分的 10%，先向下扩展，空间不足再向上扩展，直至达到向上取至 0.5 分后的最低宽度。

## 默认权重

以下权重皆为非官方训练配置。为免 15 分、25 分等题型出现 0.25 分的分项满分，先把题目满分换成 0.5 分单位，按权重计算各维度原始单位数并向下取整，再把剩余单位依“小数余数从大到小、同余数按下列维度顺序”逐一补入。由此得到的分项满分都在 0.5 分网格上，且总和严格等于题目满分。

### 归纳概括

- `task_fit` 10%：对象、范围和任务匹配。
- `content_points` 65%：独立要点覆盖与语义准确。
- `organization` 15%：分类清楚、不交叉重复。
- `expression` 10%：准确、凝练、通顺。

### 综合分析

- `task_fit` 10%。
- `analysis_chain` 70%：核心判断，以及题干要求的解释、原因、影响、关系、评价或结论。
- `organization` 10%。
- `expression` 10%。

### 提出对策

- `task_fit` 10%。
- `solution_quality` 70%：问题对应、主体与动作、对象、针对性、可执行性、情境与权限适配。
- `organization` 10%。
- `expression` 10%。

### 贯彻执行或应用文

- `genre_task_fit` 25%：身份、受众、目的、文种和内容任务。
- `content_points` 55%：应传达的信息与材料要点。
- `organization` 10%：符合实际沟通场景的安排。
- `expression` 10%：语气、称谓和表达得体。

### 复合题

先按题干动词拆成子任务。默认配置为 `task_fit` 10%、`subtask_content` 70%、`organization` 10%、`expression` 10%。`subtask_content` 再按各子任务独立评分点数量分配；每个子任务使用自身的归纳、分析或对策判断规则。不得选一个“主任务模板”覆盖其他子任务。须在阅读答案前写明分配结果。

## 缺陷归属

- 整题对象、范围或任务动词错配：只归 `task_fit` 或 `genre_task_fit`。
- 单个评分点缺失、残缺、方向错误或措施不可执行：只归对应内容维度。
- 跨评分点的分类、次序、重复或关系问题：只归 `organization`。
- 病句、歧义、冗余等句子层面问题：只归 `expression`。
- 字数、格式、错别字及卷面规则：默认只列风险，不进入上述维度；有明确细则时依细则另行配置。

## 分题型判断

### 归纳概括

评价概括对象、要点覆盖、概括层级、分类逻辑与简洁度。上位概念只有保留了材料关键差异时才算完整；未使用参考答案原词不能成为扣分理由。

### 综合分析

评价是否解释指定对象、形成核心判断，并建立材料支持的因果或关系链。不得强制套用“是什么、为什么、怎么办”。

### 提出对策

对策可来自材料明示、问题或原因的针对性转化，也可来自材料允许的合理推导。推导须展示链条。泛泛写“加强宣传”“完善机制”而未说明适用对象或动作时，只能按其实际信息量判定。

### 贯彻执行或应用文

内容完成度优先于套用公文外形。题干明确要求标题、称谓、落款、日期等时，用报告 `checks` 列为检查项和非数值风险；只有外部评分细则同时写明、且能表达为受支持的独立分项等级区间时，才进入数值维度。固定扣分或总分封顶等非加性规则触发 `limited`。

## 证据记录

每个评分判断至少含：

```yaml
criterion_id:
counting_key:
dimension_id:
expected_meaning:
scoring_units: {max: 1, awarded: 1}
prompt_evidence:
material_evidence:
answer_evidence:
judgment:
reason:
confidence:
```

`missing` 可无答案证据，但须有题干或材料依据；`uncertain` 必须引用造成歧义的答案原句及对应材料。引用取支持判断所需的最短原文。

## 常见误判

- 只认参考答案措辞，错杀同义表达。
- 见关键词便给分，忽略对象和方向。
- 把材料所有句子都当评分点。
- 把问题、原因、影响和对策混为一类。
- 同一意思跨句重复，仍重复计分。
- 用外部常识替代短题的材料依据。
- 给题干未要求的格式虚构扣分。

输出修改稿仅在用户要求时进行；修改稿不能反向证明原答案错误。
