# 申论文章训练量表 v1

## 适用范围

用于申发论述、议论文、策论文及题干允许的其他文章写作任务。量表 ID 为 `diagnostic-essay-v1`，属于非官方训练配置。

文章采用整体判断与分维度证据结合的方式。不得仅凭标题、政策词数量、段落数量、金句或模板痕迹决定质量。

## 默认权重

用户或官方细则未给权重时，先把题目满分换成 0.5 分单位，按下列权重计算原始单位并向下取整，再按“小数余数从大到小、同余数按下列维度顺序”补足剩余单位。如此分项满分均落在 0.5 分网格，且总和等于题目满分：

- `thesis_alignment` 25%：中心论点回应题干核心概念或关系，并与材料主要问题意识一致。
- `argumentation` 30%：分论点支撑中心论点，论据与结论之间存在清楚推理。
- `material_transformation` 20%：材料被概括、解释、综合并转化为论据，而非只作摘抄。
- `structure` 15%：层级清楚，段落功能明确，推进与详略合理。
- `language` 10%：准确、通顺、得体，不因病句或重复妨碍理解。

标题、文体、字数、身份或其他题干明示要求须在读答案前逐项写入 `prompt_requirements` 并生成 `requirements_lock`，随后每项恰好用一个 check 检查；默认只列非数值风险。用户细则只有能完整表达为受支持的独立分项等级区间时才用于数值评分；固定扣分、总分封顶、按比例折算或整体降档等非加性规则触发 `limited`。没有可核验规则时，不得自行执行“每个错别字扣若干分”、严重超限判零分等特殊规则。

## 维度判断

### 立意 `thesis_alignment`

- 复述文章实际中心命题，不以作者自称的主题代替全文证据。
- 检查题干限定、材料主旨、标题、开头、主体和结尾是否基本一致。
- 判断是否偷换概念、范围过宽过窄或价值方向失据。
- 不要求复述参考范文。不同观点若有题干和材料支持，且逻辑自洽，应允许成立。

### 论证 `argumentation`

- 画出“中心论点、分论点、论据、解释、结论”的关系。
- 检查因果、并列、递进和条件关系是否成立。
- 区分论据与解释；只有例子而未说明它如何支持观点，不算充分论证。
- 不强制固定数量的分论点、正反论证或名人事例。

### 材料转化 `material_transformation`

- 判断是否抓住材料中的关键事实、矛盾、关系或启示。
- 材料原句经必要概括并服务论证，可以有效；不得把一切引用都判成照抄。
- 外部事例只有相关、可信且服务论点时才有价值，不能替代材料理解。
- 未核验的外部事实只标风险，不武断认定真伪。

### 结构 `structure`

- 每段应有可辨认的功能，且与中心论点有关。
- 相邻段落应存在可解释的推进关系，避免同义重复。
- 开头建立命题，结尾完成收束即可；不强制固定模板。

### 语言 `language`

- 检查用词、搭配、指代、句意和逻辑连接。
- 文风朴素不能成为扣分理由，辞藻华丽也不能掩盖立意或论证缺陷。
- 只标真正影响准确性、可读性或作答得体性的表达问题。

## 维度等级与默认区间

- `strong`：关键要求有充分证据，标准化比例为 `[0.85, 1]`，中心取 `0.925`。
- `adequate`：总体成立，局部不足不破坏主要任务，比例为 `[0.70, 0.85)`，中心取 `0.775`。
- `developing`：部分成立，关键环节薄弱或联系不清，比例为 `[0.45, 0.70)`，中心取 `0.575`。
- `weak`：核心任务明显未完成或存在根本偏差，比例为 `[0, 0.45)`，中心取 `0.225`。
- `unassessable`：输入不足或证据冲突，不给数值。

默认量表的维度中心分等于维度满分乘以对应中心比例。先以完整精度计算，再按四舍五入将各维度分取至最接近的 0.5 分；中心总分直接等于各维度分之和，不另作事后“升档”或“降档”。总分区间把各维度比例下限、上限分别以完整精度求和；若逐维四舍五入后的中心总分位于原始边界外，先扩展边界以包含中心分，再将总下限向下、总上限向上取至 0.5 分。若宽度不足题目满分的 10%，先向下扩展，空间不足再向上扩展。边界争议须列明证据。

`overall_assessment` 用自然语言概括整篇质量，并显式指出立意、论证或材料转化中的核心短板；默认量表不另设 A/B/C/D 数值档次，避免整体档次与固定维度算法相互冲突。具体考试若有可核验的官方档次规则，按外部量表结构化录入，不套用本节等级阈值。

每个维度须写独立 `reason`，并至少绑定一项同维度 finding；一个立意 finding 不得代替论证、材料转化、结构和语言的判断依据。

## 缺陷归属

- 中心命题与题干、材料的整体错配：只归 `thesis_alignment`。
- 分论点、论据、推理和结论之间的关系：只归 `argumentation`。
- 对材料的遗漏、误读、照抄或有效转化：只归 `material_transformation`。
- 段落层级、功能、次序和重复：只归 `structure`。
- 句子准确性、通顺度和文体得体性：只归 `language`。
- 字数、标题、格式、错别字及异常作答：默认只列风险；外部规则只有可表达为受支持的独立分项等级区间时才进入数值评分，非加性规则触发 `limited`。

## 文章结构图

```yaml
thesis:
paragraphs:
  - paragraph_id:
    role:
    claim:
    evidence:
    warrant:
    relation_to_thesis:
```

`warrant` 说明论据为何支持观点。立意须引用答案、题干与材料；论证和材料转化须引用答案与材料；结构和语言引用答案即可。标题、字数、文体、身份等显式要求另用非数值 `checks` 引用题干与答案，不混入维度得分。

## 常见误判

- 用标题响亮程度代替立意判断。
- 用政策词数量代替材料理解。
- 因未使用范文措辞而判偏题。
- 将材料复述一概判为无效，或材料出现便判为有效论证。
- 机械要求三个分论点、固定五段式或名人案例。
- 让文采掩盖立意、材料或逻辑缺陷。
- 对未核验外部事实直接判错。

修改建议先处理立意与论证，再处理结构与语言。仅在用户要求时提供结构提纲、局部改写或示范文。
