# 知识口播默认风格

## 核心语感

把口播稿写成一位有判断、有分寸、略带幽默的讲述者在说话。以平实叙述为主，用具体画面和克制反差增加趣味。让人愿意听下去，也能准确听懂。

语气位于日常聊天与正式讲解之间：不像论文，也不像段子。可以用“你”“我们”和常用口语，但整体表达保持干净、稳定、有信息量。

## 默认写法

1. 用问题、具体场景、出人意料的事实或一个轻微反差开场。根据题材选择，不固定使用“你有没有过”。
2. 及早交代核心概念，再通过生活场景、历史细节或因果关系讲清机制。让例子承担解释，不在例子之后重复同一层意思。
3. 每个核心概念至少给一个可见的动作或场景。例如，不只说“人会拖延”，可以写“站立提醒一来，抬手关掉，这个动作倒是很利落”。
4. 趣味来自观察与反差。大约每 400—600 个汉字安排一到两处轻巧表达，其余篇幅认真讲事。趣味点点到为止，不追加解释。
5. 长短句交错。一个句子尽量只承担一个主要信息；连续几句较长时，用一句简短叙述换气。大声读一遍，把需要回看才能懂的句子拆开。
6. 把边界和例外写进叙述，不单独套用“当然”“不过”开启的免责段。每个边界都说明它会如何改变理解或行动。
7. 结尾回到题目本身。可以留下一个具体问题、一个小动作或一句平实判断。如果用户没有要求互动，不必固定邀请点赞、关注或留言。

## 语言尺度

| 要素 | 默认形态 |
|---|---|
| 口语感 | 使用“想聊”“赶紧去做”“这才是能做的事”等日常表达，不连续使用热梗、网络黑话或夸张语气 |
| 书面感 | 保留必要的概念、人名、引文和因果关系；接着用白话解释，不连续堆放抽象名词 |
| 趣味 | 用一个真实可见的反差调节节奏，不把每段都写成包袱或段子 |
| 态度 | 有判断但不训人，承认事情可能存在条件、代价和例外 |
| 结尾 | 收在内容上，不为了“有力”而创造可摘抄金句 |

## 一个可迁移的示例

### 调整前

> 选择悖论是指选项增加不一定提升满意度。过多选项会增加信息处理负担，并且使人更容易担心错过其他更优方案。

### 默认口播风格

> 外卖软件里有几十家店，照理说，晚饭应该更容易解决。可翻了十分钟，人反而更犹豫了。这就是选择悖论里很常见的一幕。选项太多时，我们需要比较更多信息，做完决定后，还可能惦记没选的那一家。问题不在于选择本身，而在于范围没有收窄。先确定今天想吃什么，再在几家店中比较，往往比从几十张菜单中盲选轻松。

## 常见偏差与校正

| 偏差 | 校正方式 |
|---|---|
| 把自然写成随便 | 保留概念的准确名称，用日常场景解释，不用“互相打架”“手里的不香”等网络化表达代替概念 |
| 把准确写成生硬 | 拆开长句，给抽象名词配一个动作或情境，删掉不影响理解的术语 |
| 把有趣写成段子 | 保留最能说明问题的一两处反差，其余句子回到叙述 |
| 强造金句 | 用准确判断或具体行动收尾，删掉“为昨天续费”“时间更偏爱”这类可替换的修辞 |
| 固定模板 | 依内容选择开场和结尾，不要每篇都以提问开头、以留言邀请结束 |

## 交付前检查

- 大声读时，语句是否顺口，又不像随口聊天？
- 核心概念、事实、因果和边界是否准确？
- 是否有具体画面或动作承担解释？
- 趣味点是否克制，没有连续抖包袱？
- 是否出现网络黑话、概念堆叠、强行升华或可摘抄金句？如有，改成平实叙述。
- 开场、转折和结尾是否真的由这个题材生成，而不是套用固定模板？
- 用户已经给出的人设、语气、篇幅和事实是否完整保留？
