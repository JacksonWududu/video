# 老徐 · 自媒体起号方法论 skill

把「老徐」做自媒体验证过的一套打法，提炼成**零基础也能照着用**的方法——帮你定位账号、找选题、写出站得住的口播稿，并像老徐定稿那样自检迭代。

> 老徐本人的声音只是范例。你用这套**方法**，去做出**你自己的**号。

## 它教什么

- **第 0 课 · 底层心法**：勾 / 留 / 关注、让人占便宜、替身感 / 成长感 / 活人感、起号前三篇
- **第 1 课 · 定位**：人设三问（你是谁 × 给谁看 × 凭什么信你）+ 学员自填工作表
- **第 2 课 · 选题**：把表层争论挖成「底下那道真正的题」+ **112 条母题原子库** + 选题 / 钩子 / 金句公式
- **第 3 课 · 成稿**：破 → 立 → 用 → 推 → 合，开场 40 秒法则（第一句起法看题材七选一）；四感及格线（破立给新鲜、立用给有用、推合给希望、参与串全场）+ 写稿三忌（车轱辘话 / 过度形容词 / 报幕弯弯绕）
- **第 4 课 · 五维诊断**：选题 / 开场钩子 / 逐字稿逻辑 / AI 味扫描 / 传播力
- **第 5 课 · 串联审稿**：车轱辘话 / 空形容词 / 过桥 / 首尾呼应 / 伏笔回收 + 四感终检 + 逐版修改记录
- **第 6 课 · 起号运营**：平台分工 / 冷启动 / 留量漏斗 / 变现
- **内置去味模块**：去车轱辘话 / 空形容词 / AI 腔，且**保留你的金句**（别的去味工具会把金句也删掉）

## 稿子的及格标准：四问、三忌、一个视角

每篇稿发布前过**四感终检**——四问答不上任何一问，回炉：

| 感 | 发布前一问 | 长在骨架哪里 |
|---|---|---|
| **新鲜感** | 别处听过吗？ | 破、立（反共识重新定性 + 新框架），推 补第二记 |
| **有用感** | 明天能用吗？ | 立、用（给框架 + 当面用一遍证明好使） |
| **有希望感** | 看完有劲吗？ | 推（埋下机会）、合（出路落地——哪怕是「难，但路在这」） |
| **参与感** | 有话可接吗？ | 缝上：过桥句替观众追问 / 照镜子句 / 收尾留话头 |

口诀：**破立给新鲜、立用给有用、推合给希望、参与串全场**。

语言上守**三忌**（动笔就守，不是写完再洗）：**忌车轱辘话**——一个意思只说一次，同一个句式（"是X不是Y"）一期只当 1–2 记重拳；**忌过度形容词**——删掉不损失信息的形容词一律删，要强调就换数字或场景；**忌报幕与弯弯绕**——金句直接说不预告，转场顺着讲不加戏，句子短。三忌都不碰你的金句——真金句一个字不动，这是这套去味法和别家最大的差别。

视角上**跟观众坐一边**：多用「咱 / 咱们」，少用「你 / 你们」——通篇「你」是隔着讲台说教；「你」是省着用的重拳，留给照镜子句那一两处。

## 谁适合

- 零基础想起号做自媒体的人（尤其想做口播 / 视频号）
- 有号但内容没起色、想做一次内容体检的人

## 安装

**任意 agent（Claude Code / Codex / Cursor 等）一行装（推荐）：**

```
npx skills add chenmisss/laoxu-video-script
```

**或手动 clone 到 skills 目录（最稳）：**

```
git clone https://github.com/chenmisss/laoxu-video-script.git ~/.claude/skills/laoxu-video-script
```

装完在 Claude Code / Codex 里直接说人话就能唤起（见下「怎么用」）。

## 怎么用

装好后**别研究文档——直接跟 Claude 说人话**：

- 想做号：「我是做 XX 的，想做自媒体但不知道讲什么，帮我定位」
- 有话题：「把〔某热点 / 我的项目进展〕写成口播稿」
- 写完了：「诊断一下」「四感终检过一遍」「把这段的车轱辘话去掉，别动我的金句」
- 找框架：「这个话题能挖出什么反共识角度」

skill 会带着你一步步走。
