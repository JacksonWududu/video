# 方法 · 骨架与手法

## 选题：找「底下那道真正的题」

表层争论（骂大厂、心疼打工人、AI 泡沫不泡沫）人人都在说，**不缺你一个**。老徐的活是往下挖一层，把话题重写成**一个反共识的大问题 + 一个能带走的框架**：

- 钉钉离职长文 → 「个人最优解和组织最优解为什么天然拧着」
- 自媒体焦虑 → 「观众封顶、创作者狂增，网红经济退场、IP 时代开场」
- AI 泡沫 → 用「人均 token」把口水战拉回可计算的地面

**判据**：如果一句话说不清「这期到底想让观众带走什么框架」，选题还没成。热点是入口不是主角。

**实测题材优先**：同一道题，「我拿真金白银替咱试了」永远压过旁观分析——自然流量前三（83.1 万炒股 / 57.4 万月报 / 37.1 万算命，asOf 2026-07-31）全是实测 / 实录；纯推演选题（23.1 万卖课篇）要靠逐点真案例当"实测含量"。

## 四感及格线：新鲜感、有用感、有希望感、参与感（每篇稿发布前必过）

选题成了、骨架搭了，稿子还要过一条**内容及格线**——观众看完要同时有四种感觉，缺一感就回炉：

- **新鲜感——他听到了别处没听过的东西**。来源就是上面那道「底下的题」：反共识的重新定性、一个新框架、一个没人算过的账（「人均 token」）。自查：**指出稿里哪句话是观众在别处刷不到的**；指不出来，这期就是复读机。
- **有用感——他带走了明天就能用的东西**。一个框架、一条判断标准、一个可操作的解法（「别按 star 选，按交付物选」）。这是心法里「让人占便宜」的落地。自查：**观众看完能复述出什么、用在哪**；只有情绪没有交付物＝白看。
- **有希望感——他看完更有劲，而不是更丧**。批判归批判、现实归现实，落点必须给出路——哪怕是「难，但路在这」。老徐收尾的双向祝福就是这个逻辑。自查：**看完的情绪是往上还是往下**；只收割焦虑不给路，流量再快也是翻车流量（红线见 `redlines.md`）。
- **参与感——他不是看客，稿子里有他的位置**。他的问题被替他喊出来（「肯定有人要抬杠了」）、有照镜子句直接看着他说（「你在组织里窒息的那个瞬间」）、收尾留一个他能接的话头（打赌式收尾 / 一个值得吵的具体问题）。自查：**看完他有话可接吗、评论区有事可做吗**；评论和互动是算法给量的硬通货——参与感是四感里唯一直接长在推荐机制上的。

四感对应四问：**别处听过吗？明天能用吗？看完有劲吗？有话可接吗？**——写完自问，答不上就改。

四感怎么长在稿上，分两种。**前三感长在拍上**，逐拍交付：评论类记口诀——**破立给新鲜、立用给有用、推合给希望**（逐拍标注见下节「主骨架」）；讲解 / 干货类同理：问题选得刁＝新鲜、答得正面＝有用、解法落到「你能做」＝希望。**参与感长在缝上**，不归哪一拍独占：过桥句本来就是替观众喊出的追问、照镜子句盯着他说、收尾留话头——衔接处全是它。全口诀：**破立给新鲜、立用给有用、推合给希望、参与串全场**。

## 主骨架：破 → 立 → 用 → 推 → 合（前三感长在拍上，参与感串在缝上）

对评论类稿子，这套五拍最稳（钉钉那期就是——注意它未发布、无播放验证；账号数据背书的主力是问答 / 推演骨架，见「底层引擎」）。**四感不是写完再补的外挂**——新鲜 / 有用 / 希望是分到每一拍的交付任务，写到哪一拍，就该给观众哪种感觉：

1. **破**：拆掉大众默认的那个叙事（善恶 / 英雄恶龙 / 非黑即白）。给出「它其实是 X」的重新定性。→ **新鲜感第一落点**：这句重新定性，就该是观众在别处刷不到的那句话。
2. **立**：抛出全片核心框架（结构性冲突 / 单位经济学 / 目标函数夹角）。这是要观众带走的那颗种子。→ **新鲜感坐实、有用感开账**：框架既是新东西，也是他能带走的工具。
3. **用**：拿这个框架去拆事件里的第二层冲突（把框架用一遍，证明它好使）。→ **有用感兑现**：当着观众的面用一遍，他才信「我也能拿去用」。
4. **推**：推向行业趋势 / 未来（信息量最大的一段，AI / Agent / 组织形态）。给出「反直觉但成立」的判断。→ **新鲜感第二记，顺手埋希望**：趋势里要看得见机会，不能只有海啸。
5. **合**：收束回开头那道题，落到观众自身；片尾接个人自我代入（签名 / 口头禅只在合身的特定内容带，见 `persona.md`）。→ **有希望感落地**：出路给在这一拍——哪怕是「难，但路在这」。

**参与感不认拍，查缝**：三处过桥句是不是替观众喊出的追问、有没有照镜子句盯着他说、收尾有没有留话头。一拍（或一缝）没给到位，对应的感就缺——**四感终检（`diagnostics.md` 总检）查出缺哪感：缺前三感修对应的拍，缺参与感修缝**。短稿（AI 泡沫式 7 分钟）可压成「钩子 → 一个反直觉计算 → 一个结论」，四感照样齐：计算给新鲜、结论给有用、落点给希望、话头给参与。广告稿走另一套（见 `motifs-and-lines.md` 广告稿桥法）。

## 底层引擎：按"观众的问题顺序"往前走（长视频真骨架）

老徐的长视频，本质是**按观众脑子里问题冒出来的顺序，一个个接住**。动笔前先在脑子里坐一个观众，反复问自己：**他看到这儿，下一句会想问什么？** 接住它、正面回答、再往下逼一层。

**这套引擎是账号里唯一被播放数据验证过的结构**（asOf 2026-07-31）：自然流量前四——83.1 万 AI 炒股、57.4 万二月总结、37.1 万 AI 算命、23.1 万卖课推演——炒股 / 算命 / 卖课全篇「问一步答一步」，月报开门就答「股东最关心的钱」；前三实测实录，第四靠逐点真案例（另有转转 MacBook 46.6 万，商单口径单算）。而破立用推合的旗舰样例（钉钉）从未发布、无验证——评论类用五拍时，心里要有这个数。

**骨架 · 预判问题 → 回答 → 解法**（讲解 / 干货 / 拆解类默认，如企业转型、一人公司的坑、API 中转站、高考顾问）：
```
观众此刻会问什么（预判）→ 正面回答（不绕）→ 他紧接着会问什么（再预判）→ 再答…… → 落到"所以你该怎么做"（可操作解法）
```
一环扣一环，观众会有"你怎么知道我正想问这个"的感觉——**这就是替身感的来源**。

**显性标记**（你真稿里到处是，可直接用）：「肯定有人要抬杠了：那 ChatGPT 呢？」「肯定有人会问：既然 OPC 不值得投资……」「你可能觉得自己的工作很普通……」「问得好。」——把观众的问题**替他喊出来**，再答。

**三种骨架、同一个引擎**：
- **评论类** → 破立合（见上）其实是这引擎的特化——那三处**过桥句，就是"预判的下一个观众问题"**（"那正确的打开方式是什么？"）。
- **讲解 / 干货类** → 直接"问一句、答一句、最后给解法"，更朴素也更好带小白。**多块内容的排序按重要性降序，不按操作 / 购物顺序**——最重的先讲、最轻的垫底，并把"为什么这么排"说给观众听（"先内容，再剪辑，最后设备——时间就该按这个顺序分"），顺序本身就成了观点。
- **推演 / 解题类**（范例：一人公司卖课篇，自然流量第 4）→ 开头立一道**具体到数字的题**（"普通人做一人公司，最快怎么赚到 100 万"），当着观众面推演到底：给模型（100 个有钱人 / 1000 个中产 / 1 万个普通人）→ **先杀最直觉的答案**（新手都选的套壳路，死亡率 80%）→ 反例救回（刘小排）→ 一个历史比喻当核心框架（石英表 vs 机械表）→ 分类穷举、**每类配一个真案例** → **结尾把中间产物拼成观众的对号入座表**（护城河 × 赛道 × 三模型）→ 拿全片框架出一道关于自己的题，评论区过招。纪律：推演稿没有实验，**案例就是它的实测含量**——每个抽象论点必须配一个具体的人 / 店 / 数字。
- **开场也是预判**：第一句先接住的，是"这话题跟我有啥关系"这个隐问题（起法七式见 `formulas.md`）。

判据：写完回看，每一段的**开头**是不是在接住"观众此刻的问题"？如果是自顾自往下讲、没接住问题，观众就会划走。

## 开场 40 秒法则（前摇短是铁律，第一句看题材）

**铁律两条，什么题材都守**：
- **前摇必须短**：40 秒内抛出核心钩子（那道大问题 + AI/趋势钩子）。利益披露、背景铺垫压成一句带过（钉钉 v3→v4 把前摇从 600 字砍到 310 字，就是这条）。
- 开场必给一句**定调句**决定观众用什么预期看完（「钉钉只是入口，不是主角」）。

**第一句怎么起，看题材挑**（起法公式见 `formulas.md`，全部来自老徐 30+ 篇真稿）：悬念数字（「咱猜猜看，全世界在用顶级 AI 的人究竟有多少？」）、生活场景（收衣服数出一年只买三四套 → 引出服装行业）、反预期（「不聊 AI，聊一道除法题」）、报题+情感钩子（「这个话题我憋了两个多月」）、反流量式（「大概率没什么流量的话题」）。

**反流量式是特定题材专用，不是默认**——语料 30+ 篇里只有钉钉一篇这么开：话题天然圈内小众、流量做法已被做滥时，以退为进才成立。干货 / 开源 / 里程碑类更别碰——这类内容的钩子就是价值本身，第一句直接抛最大的便宜（「破四万粉，全流程开源，任何人可照抄」），先自贬三句只会把人劝走。

## 过桥句：让逻辑像现场想到的追问

段与段之间用一句**追问式过桥**挂钩，语气像临场想到，不是念小标题：
- 「如果好人坏人都不是正确打开方式，那正确的打开方式是什么？」
- 「在钉钉内部做不成，离开钉钉就能做成吗？」
一篇至少埋 3 处，串起破→立→用→推。过桥就这一句追问，别加戏——「慢着——剪映？」式的恍然表演是弯弯绕，顺着讲。

## 扣环螺丝：一颗贯穿全片的话（长稿装置，短稿不装）

**适用范围先说死**：扣环是 **11 分钟上下评论深稿**的装置，一期最多扣**两次**（钉钉那期就是两次），每次含义必须真加深。**几分钟的干货 / 流程稿别装扣环**——主线句说一次自己会立住，短稿里的重复只剩啰嗦（四万粉稿曾扣三次，被毙）。

选一句**能重复出现、每次含义加深**的话，把几个思考拧成一个整体：
- 钉钉那期＝「位置筛选人，位置也定义对错」（思考二讲人，思考三讲战略，同一句扣两次）。
- 自媒体那期＝「别按 star 选，按交付物选」/「流量是租的，留量才是你的房子」。
伏笔也要回收：开头埋的比喻（「城墙」），片尾要再用一次（「还没有城墙的新地方」）。

## 公道话 / 对称分析（老徐的招牌可信度）

全片至少有一处**主动替被批评的一方说公道话**：「说句公道话——」。这是「位置决定对错」的落地，也是和「站队式流量号」拉开差距的地方。冲突双方做对称分析，不裁决个人（详见 `redlines.md`）。

## 情感曲线：靠重拳和留白造节奏

- 每期安排 1–2 记**重拳金句**（「系统逼你加班你会反抗，理想让你加班你会感谢」），放慢、说完留白一拍。
- 理论段（科斯 / 单位经济学）语速放慢，但**讲完必须立刻落地**，不让理论悬空。
- 论点高峰放在「推」（趋势段），收尾快收不复读，个人坦白后置做情感锚点，收尾上扬。
- 成稿要画一条 ASCII 情感曲线自检节奏（模板见 `format.md`）。

## 写稿三忌：车轱辘话、过度形容词、报幕与弯弯绕（动笔就守，别指望写完再洗）

`de-ai.md` 是写完后的去味手术，但最好的手术是不用做——这三条在**写的时候**就守住：

- **忌车轱辘话：一个意思只说一次**。最容易犯的三个位置：每段结尾自我总结一句、换个同义说法再绕一圈、开头预告 + 中间讲 + 结尾复述等于讲三遍。规矩：**结论说一次，说完就往前走**。**句式也算**：「是 X，不是 Y」这类重定性句式一期只配当 1–2 记重拳，满篇复用＝句式级车轱辘；具体话说完再补一句比喻重定性（「它管结构咱管味道」后面再跟「AI 是编辑不是作者」）是赘述，删比喻、留具体。扣环螺丝的例外只在长稿成立（见「扣环」节），短稿没有例外。
- **忌过度形容词：形容词是懒惰的证据**。「巨大的机会」「深刻的变革」说了等于没说。规矩：**一个形容词删掉不损失信息，就删；要强调，用数字、场景或比喻**——「巨大的机会」不如「一年多挣二十万的机会」，「深刻的变革」不如「以前十个人的活，现在一个人干」。金句靠对称和重定性立住，不靠形容词，所以这条不伤金句。
- **忌报幕与弯弯绕：直接说，顺着讲，句子短**。说金句之前不介绍金句（「核心就一句话，今天会出现三次，第一次放这」——删报幕，直接说那句）；转场不加戏（「慢着——剪映？开头挖的坑现在填」——顺着讲就行），过桥就一句追问；一句话只装一件事，一口气念不完就拆。**但别砍成电报**：名词冒号断片体（「毛边，三样：」「最后一关，最轻：设备」）嘴说不出来，是 AI 味的另一个极端——完整的口语句，该有的主语、连接、语气词都在。判据：**大声读，嘴顺不顺**。几分钟的稿子，经不起弯弯绕绕，也经不起念电报。

写时守住这三条，第 4 课的去味就只是复查，不是重写。

## 创作视角：跟观众坐一边——多用「咱」，少用「你」

口播稿的默认人称是**「咱 / 咱们」**：「咱把这笔账算一算」「咱这些做内容的」。这是替身感 / 成长感（「我们一起」）在语言上的落地——「咱」是坐在观众旁边说话，通篇「你 / 你们」是隔着讲台点名，说教味多半从这来。

- **「你」是省着用的重拳**：全片留给一两处直击位——**照镜子句**（「你在组织里窒息的那个瞬间…」看着镜头说），或**收尾鼓励**（「我能做到，你也就可以」「我期待你的作品」）。正因为全片都是「咱」，这一声「你」才扎得进去或暖得起来；你字满天飞，直击位就没了力气。
- **引文原话不改**：引用别人的话、还原对话场景，照原文。
- 自查：通读数一遍「你」——除了照镜子句和引文，**能换「咱」的都换**。
