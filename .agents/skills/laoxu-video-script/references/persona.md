# 第 1 课 · 定位你自己的账号

起号第一步不是拍视频，是想清楚**你这个号凭什么让人记住、让人信**。人设不是演的，是**定位**——把"你本来就是谁"提纯成一句话。

## 人设三问（学员先填这个，再谈内容）

1. **你是谁？** —— 你的真实身份 / 经历 / 手艺里，最有差异化的那一个标签。（不是"热爱生活的女孩"，是"做过 8 年供应链、现在一个人做跨境的老板"。）
2. **给谁看？** —— 具体到一类人和他们的一个痛点。观众越具体，内容越有劲。
3. **凭什么信你？** —— 你能拿出什么别人拿不出的**证据/视角/现场**？（一线经历、真金白银的踩坑、独家数据、反共识的判断。）

**一个好人设的判据**：具体（不是形容词）、有立场（敢下判断）、可持续（能日更三年不塌）、有记忆点（一句话能被观众复述给别人）。四条缺一条，回去改。

## 范例：老徐是怎么填的（学这个"填法"，不是抄这个"内容"）

- **你是谁**：一人公司实践者 + 投资人视角 + 前大厂打工人（三合一，这三个标签互相加成，别人难复制）。
- **给谁看**：想用 AI 一个人干成事的普通人（他管观众叫「精神股东」）。
- **凭什么信**：真的在一个人 + AI 地干、真做过投资会用框架拆问题、真从大厂出来但不消费前东家。
- **固定资产**（每个成熟的号都该有几件，观众靠它认出你）：
  - 观众称呼：「精神股东」
  - 口头禅：「去动手，去动手」
  - 签名收尾：「命由己造，事在人为。神机妙算，不如自己说了算。我是老徐，中年辍班，All in AI 的一人公司创业者。」
  - 招牌手法：「说句公道话」、替观众喊问题（"肯定有人要说"）、把个人经历放片尾做自我代入。

**固定资产是衣柜，不是制服**：观众称呼可以常用；**口头禅和签名收尾只在合身的特定内容用**——老徐的签名挂着命理产品梗，只配特定期；「去动手」拢共没用过几次。次次都戴＝人设变模板，一眼假。写稿别默认往结尾贴签名。

## 学员工作表（填完再进第 2 课）

```
我是谁（一个差异化标签）：__________
给谁看（一类人 + 一个痛点）：__________
凭什么信我（我的独家证据/视角）：__________
我的观众我想叫他们：__________
我的口头禅/固定收尾（设计一句你自己的）：__________
我绝不碰的红线（例：不消费旧东家、不编数据）：__________
```

## 红线：造你自己的，别套老徐的
老徐的「双机党/精神股东/命由己造」是**他的**固定资产，套过来你就成了低配模仿号。你要用同样的"三问 + 固定资产"方法，长出**属于你的**那套。人设可以有缺点、可以不完美，但必须**是你**、且**一贯**——信任是复利，装出来的完美是负债。
