# 第 6 课 · 起号运营（把一篇稿，变成一个号）

会写单篇 ≠ 会做号。这一课把方法接到"经营"：发在哪、按什么节奏发、怎么冷启动、怎么把看的人变成自己的人。

## 一、平台分工：别四处平均用力
四个平台性格不同，按**角色**用，一主一辅起步：
- **抖音 = 放大器**：公域最大，练钩子、测选题、抓新客。算法分发，粉丝≠触达。
- **小红书 = 资产库**：65% 流量来自搜索，发**能被搜到的干货**，吃长尾——今天的内容半年后还在带客。
- **B 站 = 信任场**：粉丝真的回来看更新，一条深度顶十条碎片。
- **视频号 = 枢纽**：连着微信，是把公域观众**接进你私域**的那扇门。

## 二、冷启动：前 20 条怎么发
- **开局前三篇是重头戏**，单独打一套组合拳（你是谁 / 大便宜 / 活人）——见 `references/qihao-xinfa.md`「起号前三篇」。
- **别追爆款，先立"人设+选题范围"**：前 20 条让人一眼看出"这号是干嘛的、这人是谁"。
- **同一个母题，多个角度打**：用第 2 课的母题库，一个框架拆不同热点，观众重复看见=记住你。
- **完播 > 涨粉**：新号先把单条做到"看完"，算法才给你下一波（各平台都在奖励留存，不只涨粉）。
- **固定资产尽早上**：称呼、口头禅、签名从第一条就用，攒辨识度。

## 三、内容节奏
- 稳定 > 爆发。定一个你能扛三年的频率（哪怕周更）。
- 选题配比参考：**7 分"能被搜到/能带走框架"的干货 + 3 分蹭热点**。热点是获客成本，干货是固定资产。

## 四、留量漏斗：把流量变成"你的人"
```
公域（被看见：抖音/小红书） → 私域（被记住：微信/社群/视频号） → 产品（收钱：课程/服务/自己的东西）
```
- **别只攒粉丝（粉丝是平台的），要往私域沉**——那是算法动不了的自留地。
- 变现结构立个目标：**广告收入 ≤ 1/3**，其余来自你自己的产品/服务。广告是别人的预算，产品才是你的生意。

## 五、迭代：像老徐定稿那样运营
- 每条内容发完做一次**第 4 课的诊断复盘**（尤其钩子和 AI 味）。
- 数据不好别慌，先问是哪一维塌了：选题？开头？逻辑？还是根本没记忆点？——对症改，别整条推倒。

## 一句话给学员
**以前拼谁被更多人看见，以后拼谁被同一群人反复相信。** 起号不是赌一条爆款，是用这套方法，把"你是谁、你对谁有用"这件事，一条一条讲清楚、讲到别人信。
