# 第 0 课 · 底层心法：为什么有人关注你，并留下来

前面几课是「术」（破立合、格式、诊断），这一篇是「道」。带学员**从这一课开讲**——不先想明白"人凭什么关注你、凭什么留下来"，招式练得再溜也是空的。

## 一条内容的三个动作：勾 → 留 → 关注
任何一条内容，都要连过三关，缺一关前功尽弃：
- **勾（3 秒进得来）**：刷到的人凭什么不划走？开头给反差、痛点、或"替身钩子"。→ 对应诊断 **D2 开场钩子**。
- **留（看得完）**：中间凭什么不走？一层层给、留悬念、别啰嗦、别注水。→ 对应 **D3/D5**。
- **关注（留得下）**：看完凭什么点关注？因为他**占到便宜**了，还感觉你是个**值得追的活人**。
> 勾不住＝0 播放；留不住＝完播低、算法不给量；关注不了＝白涨一波过路流量。三关是递进的。

## 让人占便宜：你到底能分享什么？
起号的底层交换：**观众用注意力，换你的价值——让他每次都觉得"赚了"。**
- 先问自己一句狠的：**凭什么是你？** 你有什么别人给不了的：一线现场、真金白银的踩坑、独家数据、反共识的判断、一个能立刻上手的方法？
- "占便宜"的三种给法：**学到**（干货/方法）、**爽到**（情绪/共鸣/替身）、**省到**（帮他避坑、帮他做决定）。一条至少占一样。
- 宁可一条**把一个小点讲透**，让人惊"这也白给？"，也别一条泛泛而谈、留下"又是正确的废话"。
- 铁律——**别舍不得**。新号最怕藏着掖着；把压箱底的先给出去，信任才起得来。

## 为什么关注"你这个人"：替身感 + 成长感
涨粉分两种：粉「内容」的会流失，粉「你这个人」的才留得住。让人粉你，靠两种感觉：
- **替身感**：你替观众**活了他想活的人生 / 做了他不敢做的事 / 试了他想试的东西**。"看你，就好像我也做了。"（老徐的"一个人 + AI 把公司干起来"，就是一群想单干的人的替身。）→ 想清楚：**你在替谁活着？**
- **成长感**：让观众跟你**一起打怪升级**——你在变强、在踩坑、在往前走，他追的是这部"连续剧"。别一上来就"我是大神"，要"我们一起"。→ 敢不敢把**没做成的、正在做的**也摆出来？

## 活人感：你的真实感受，就是护城河
现在最贵的不是完美，是**活人**。满屏 AI 生成的完美内容里，一个有感受、有缺点、有具体现场的真人，天然稀缺。
- **有感受**：讲事之外讲**你的感受**——你为什么生气 / 兴奋 / 犹豫。观众记不住信息，记得住情绪。
- **有缺点**：忍住没买 M5 Max、"连诗都不怎么写了"——不完美才可信。
- **有现场**：具体到你今天用哪台机器、学员在 Windows 上怎么翻的车。抽象让人走神，具体让人相信。
> 这就是诊断 **D4 AI 味扫描**的正面版：目标不是"去掉 AI 味"，是"**加上活人味**"。

## 起号前三篇（把心法落成开局三步）
新号前三篇不是随手发，是一套组合拳，把"勾 / 占便宜 / 活人"各打一发，把账号雏形立住：
- **第一篇 · 你是谁（勾 + 替身感）**：一句话说清你是谁、能给谁什么、凭什么是你，抛一个"我也想成为这样"的替身钩子。让人三秒决定要不要关注。
- **第二篇 · 大便宜（占便宜 + 建立"关注你不亏"）**：给一个具体到"这也免费？"的干货/方法，让第一篇勾来的人**立刻尝到甜头**——把"关注你＝占便宜"这个印象砸实。
- **第三篇 · 活人（留 + 成长感）**：露一次真实的你——一个感受、一段踩坑、一个正在打的怪。把"账号"升级成"人"，让人从"这内容有用"变成"这人我得追"。
> 三篇打完，一个「有用 + 是个真人 + 我想成为」的账号就立住了。之后就是用这套心法持续供货。

---
**心法接回六课**：勾＝D2，留＝D3/D5，占便宜＝选题（第 2 课）得让人带走东西，替身感/成长感＝定位（第 1 课），活人感＝AI 味扫描（D4）的正面。**心法是"为什么"，六课是"怎么做"。**
