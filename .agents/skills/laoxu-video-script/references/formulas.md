# 公式库（把手感沉淀成可复用公式）

## 选题公式：表层争论 → 底下那道题
```
大家都在吵：{表层争论}
但底下真正的题是：{一个反共识的结构性大问题}
这题和每个人有关，因为：{AI/趋势钩子把话题抬高}
→ 所以 {热点} 只是入口，不是主角。
```
例：大家都在心疼钉钉打工人 → 底下是"个人最优解和组织最优解为什么天然拧着" → 因为只要你在组织待过就遇到过 → 钉钉只是入口。

## 开场钩子公式（七选一起手，40 秒内收；按题材挑，有自然播放背书的优先学）
1. **硬数据 / 悬念式**（**37.1 万自然播放**·AI 算命「烧了四百多美金、跑了两万多次调用，得出一个出乎意料的结论」；炒股篇的实验承诺「2000 块完全听 AI 的，看能赚多少」同款）：反直觉数字或成本前置；或抛给观众猜（「咱猜猜看，{反直觉的量} 究竟有多少？」超级订阅者篇）。
2. **报题 + 情感钩子式**（**57.4 万自然播放**·二月总结「这是我中年辍班第一个月的真实情况」）：直接说聊什么，配一个值得看的理由（真实情况 / 憋了两个月）。
3. **质疑式**（**23.1 万自然播放**·一人公司卖课篇）：把观众心里最狠的怀疑当第一句（「一人公司到底做什么能赚钱？是不是最后都得去卖课？」），配一句资格声明（"躬身入局的一人公司创业者"）和预期管理（"偏理论有点枯燥，但有想法强烈建议看完"）；先顺着质疑给足弹药（"10 个里 9 个真在卖课"），再用数据反转（3000 万一人公司 / 1.7 万亿产出）。
4. **亮答案式**（46.6 万·转转 MacBook，**商单，播放含投放可能，招式可学、数据别当纯内容证据**）：第一句直接给结论和价格（「四千到五千块，一台二手 MacBook Pro，就是你进入 AI 世界性价比最高的入场券」），整期论证它。
5. **生活场景式**：从自己身上的小事切入，数着数着数出问题（收衣服数出一年只买三四套 → 服装行业 AI，99 元 T 恤篇）。
6. **反预期式**：「今天不聊 {大家以为你要聊的}，聊 {一个小切口}。」（"不聊 AI，聊一道除法题"，AI 泡沫篇）
7. **反流量式（特定题材专用；唯一样例钉钉未发布、无验证）**：话题天然圈内小众、流量做法已被做滥时才考虑；干货 / 里程碑 / 普适话题一律价值前置。
收尾都接一句**定调句**："{热点} 只是入口，不是主角。"

## 金句模式公式（可批量造，但一期只留 1–2 记重拳）
- **重定性**：「这不是 {大众叙事 A}，是 {重新定性 B}。」（不是系统杀死天才，是两个都没错的目标函数）
- **对称句**：「{同一件事} 在 A 叫 {褒}，在 B 叫 {贬}。」（在钉钉叫自杀式创新，在创业公司叫从零到一）
- **反转燃料**：「{压迫式} 你会反抗；{自愿式} 你会感谢。」（系统逼你加班/理想让你加班）
- **租 vs 有**：「{X} 是租的，房东是 {平台}；{Y} 才是你自己的房子。」（流量/留量）
- **位置式**：「不是 {某人} 天生 {坏}，是位置在筛选人。」
- **落地式**（给理论收口）：「{某人愤怒的那些东西}，本质上全是 {一个经济学概念}。」（协调成本）

**用量红线**：这些句式一期只当 **1–2 记重拳**用。同一句式（"是X不是Y"/对称）满篇复用＝句式级车轱辘；具体话已经说完、再补一句比喻式重定性＝赘述，删比喻、留具体。老徐的可引用句是**判断直给**（"通顺不值钱了"），不是修辞装置——比喻留给整段真故事（石英表 vs 机械表），句子里说大白话。**干货 / 流程稿甚至可以一记不留**：老徐终版用经验话化解（"差点意思""搞了半天还不如我古法搓的快"），狠判断句主要是评论稿的武器。

## 广告稿桥法公式（转转那套，V 字情感曲线）
```
惊讶高点：{产品/装备} 真香 —— 用老徐自己的装备线起（双机党、看中 M5 Max）
自嘲低点：但 {贵/现金流} —— 一人公司忍住没买，自嘲
开窍上扬：所以 {产品的解法}（二手/平替/性价比）—— 把"贵"转成"聪明地买"
收尾钩子：埋续集（"赚到钱买 M5 Max 开箱跟精神股东汇报"）
```
铁律：广告的产品必须织进老徐**自己的钱包/装备故事**当暗线，不是硬广插播。商单标杆＝转转 MacBook v9（46.6 万播放，asOf 2026-07-31；商单口径，与自然内容分开算）。

## 结构节奏公式（评论稿默认）
`开场(40s 内钩子+定调，起法七选一) → 破(拆旧叙事) → 立(核心框架) → 用(框架拆第二层) → 推(趋势高峰) → 合(快收+个人坦白后置；签名合身才带)`
