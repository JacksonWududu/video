# 第 3 课配套 · 成稿格式

一份能直接开录的稿，除了正文，还要带上录制和迭代要用的"仪表盘"。以下每块都可直接粘贴填充。

## 1 · 题头元信息（稿子最上方）
```
# {主标题：一句话说清这期的核心判断}（vN）

> 预估时长：{11–14} 分钟 | 人设：{你的定位一句话}
> 形式：坐播，口语化，{题材：实测实录 / 讲解 / 推演 / 评论}
> 核心论点：{观众要带走的那个框架}
> 情感线：{开场→钩子→重拳→拆解→趋势→个人坦白→收束}
> 立场红线：{全片唯一批判的对象是什么——只批结构不批个人}
> 四感自检：新鲜＝{观众别处刷不到的那句} | 有用＝{观众带走什么} | 希望＝{落点给的出路} | 参与＝{留给观众的话头}
```

## 2 · 分段时间码正文
每段用 `## 【{起}–{止} 段名】` 起头。段名用**内容**不用套话（"思考二：个人最优解 vs 组织最优解"，不是"第二部分"）。加粗**重拳句**和**框架句**，方便录制时找重音。

## 3 · 金句列表
```
## 金句
1. {可单独截取、能当字幕卡的一句}
...
```
一期沉淀 8–18 句，但录的时候**重拳只留 1–2 记**，其余是节奏里的小亮点。

## 4 · 录制提示（逐 beat）
```
## 录制提示
- **{某句}**——{语气/停顿/看镜头/放慢/留白一拍}
```
标出：开场语气、每处过桥句的追问感、重拳句的留白、照镜子句看镜头、收尾的落点。

## 5 · 情感曲线（ASCII，自检节奏）
```
## 附：情感曲线
开场       ███
钩子       ████
重拳①      ██████   ← 第一记重拳
谷底蓄力   █████
论点高峰   ███████  ← 趋势段
快收       █████
个人坦白   ██████   ← 情感锚点，后置
收束       ████████
```

## 6 · 结构导览表
```
## 附：结构导览
| 段落 | 时间码 | 叙事动作 | 一句话记忆 |
|------|--------|----------|------------|
| 开场 | 0:00–0:40 | 反流量定调+抛钩子 | {记忆点} |
```

## 7 · 逐版修改记录（定稿留痕）
```
## 附：逐版修改记录
**v1 → v2**
- {改了什么，为什么}
```
这块是老徐迭代法的核心——**每次改都记一句**，下次接着改有地图，也是给学员看"稿是改出来的，不是一遍写成的"。
