# 第 4 课配套 · 去车轱辘话 · 去 AI 腔

> 口播稿最大的 AI 味不是用词，是**啰嗦**——同一个意思翻来覆去说、每段都自我总结、正确的废话堆一堆；第二大是**空形容词**堆出来的宣传腔。这是老徐定稿时的"去味手法"，和 D4（AI 味扫描）、D5（串联审稿）一条线：D4/D5 负责揪出来，这里负责改干净。

## ⚠️ 先记这条：去味不许动你的金句（最重要）
很多"去 AI 味"的做法有个通病——把一切"像可引用的句子"都当 AI 腔删掉。**对老徐的稿，这是灾难**：你的对称句、金句、扣环螺丝，是**故意打磨的招牌**，不是 AI 味。所以去味只有一条铁律：
- **真金句**（有具体内容撑着的对称句 / 重定性，如"流量是租的，留量才是你自己的房子"）→ **留，一个字别动**。
- **假金句**（空洞排比、万能句、正确的废话，如"拥抱 AI、学习 AI、使用 AI"）→ 删。
- 对称句、并列，只要是你**故意**用来扣逻辑的，保留；只删 AI **无意识**的凑数排比。
> 一句话：**去味只杀啰嗦和腔调，不杀框架和金句。**

## 去味清单（口播稿高频 · 按杀伤排序）
1. **车轱辘话（头号）**：一个意思说两三遍、每段结尾都自我总结一句、换个同义词再绕一圈 → 合并成一次说清。**同一个句式反复用也算**：「是 X，不是 Y」一篇出现四五次＝句式级车轱辘，只留当重拳的那 1–2 记。
   > 例：「AI 时代来了。在这个 AI 时代，每个人都有机会。可以说，AI 时代谁都躲不掉。」→「AI 这波，谁都躲不掉。」
2. **空形容词 / 宣传词堆（二号）**：前所未有的 / 巨大的 / 深刻的 / 全方位的 → 判法：**删掉不损失信息的形容词，一律删**；要强调，换具体的数字或场景（"巨大的机会"→"一年多挣二十万的机会"）。金句靠对称和重定性、不靠形容词，这条不碰金句铁律。
3. **AI 连接词 / 起手式 / 报幕腔**：值得注意的是 / 因此 / 此外 / 不仅…而且 / 可以说 / 综上所述 / 在这个时间点 → 删，或换成你的口语（其实、说白了、你看、我跟你讲）。报幕腔＝说一句话前先介绍这句话（"接下来这句很重要""今天会出现三次"）→ 删报幕，直接说那句。
4. **凑数三段式**：硬凑三项显得全面（"占据先机、赢得主动、脱颖而出"）→ 砍到两项，或一句话。
5. **万能积极结尾 / 肤浅收尾**："未来一片光明""展示了其重要性" → 删，或落到一件具体的事上。
6. **过度软化**："可能潜在地或许会有一些影响" → 直接下判断（你本来就敢下判断）。
7. **讲台腔「你」**：通篇对观众「你 / 你们」＝隔着讲台说教 → 换「咱 / 咱们」坐到同一边；「你」省给照镜子句那一两处（引文原话除外）。
8. **视觉噪音**：破折号、粗体、emoji 泛滥——口播稿是"说出来"的，这些一律清。

## 去完别忘了"加活人味"（去味的另一半）
删干净不等于好——无菌的白开水稿一样一眼假。**人味来自暴露，不来自修辞**（对照老徐定稿提炼的五个特征）：
- **有现场（流水账细节）**：烧了四百多美金 token、拍视频打光就用个头灯、命理 App 提醒该注意身体了——具体到钱数和物件。抽象让人走神，具体让人信。
- **有暴露（穷、怂、拧巴摊开说）**："经费不足啊——Opus 最贵的都拿了，就不用 ChatGPT 了""白皮书里我老老实实叫三重偏倚控制，没敢标三盲""说过要信奉科学，偏偏做了个算命 AI"。自己的小气和自相矛盾直接说出来，这是 AI 装不出来的。
- **有活话（网络口语）**：好家伙 / NONO / 榜一大哥 / 巴拉巴拉 / 躺赚 / 主打一个听劝 / 古法手搓 / 大道至简 / 神来一手 / 说真的哈 / 一股脑 / 足矣 / 差点意思——活人嘴里的词，按自己的习惯用，别硬塞。
- **有呼吸（絮叨不是罪）**：真实口语带补充和自我更正（"本来我做了个网页，试了好几次都没那种感觉，所以还是录口播"）。**三忌杀的是废话和复读，不杀呼吸**——名词冒号断片体（"毛边，三样：""最后一关，最轻：设备"）就是剪过头的样子，嘴说不出来；完整的口语句才是人话。口头禅、停顿、用词小毛病别修，但**嗯嗯啊啊的纯气口可以适当修**——留习惯，去噪音。
- **慎造比喻句（修辞是重灾区）**：句子级的精巧比喻 / 对仗装置（"换来的是一柜子吃灰的机器，和一条没时间打磨的稿子"）是 AI 味的高级形态。老徐的比喻是**讲一段真故事**（石英表 vs 机械表讲半分钟），句子里说大白话。稿子改了六七版还不像人话，多半是修辞方向错了：往外删修辞，往里加暴露。**概念命名同理**：用他词汇体系里已有的词（「活人感」），别替他发明新概念词（「毛边」在终版被本人删掉）。

## 工作流
① 先跑 D4 揪出 AI 味 → ② 按清单逐段改（**守住金句铁律**）→ ③ 大声读一遍，拗口就是没改干净 → ④ 再对一遍活人味 → ⑤ 改动记进逐版修改记录。
