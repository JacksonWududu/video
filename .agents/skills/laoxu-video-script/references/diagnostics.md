# 诊断模块（诊断，而不只是生成）

老徐定稿的功夫，不在"帮你写"，在"帮你查"。这里把它拆成 **5 个可单独调用的诊断**——既能在写完后逐个跑，也能单独拎出来用（"帮我诊断这段开头"）。每个诊断只做一件事，输出**红黄绿 + 具体改法**，不空泛夸。

---

## D1 · 选题诊断（这题值不值得做）
- [ ] 能不能一句话说清"观众看完带走什么框架"？说不清＝红。
- [ ] 是不是只停在表层争论（骂大厂/心疼打工人/泡沫不泡沫）？是＝黄，往下挖一层。
- [ ] 有没有一个**反共识**的重新定性？（"这不是英雄恶龙，是两个都没错的目标函数"）
- [ ] 有没有**实测成分**——真金白银、真实验、真现场（"我花了 X 替咱试了"）？自然流量前三（83.1万/57.4万/37.1万，asOf 2026-07-31）全有；纯推演选题（23.1万卖课篇）要逐点配真案例顶上；纯旁观评论（钉钉式）未发布、无验证。
- [ ] 能不能挂上 `motifs-and-lines.md` 里某个母题？能＝绿。
> 全红重选题，别硬写。

## D2 · 开场钩子诊断（前 40 秒，仿 /dbs-hook）
- [ ] 第一句的**起法配题材吗**？（五种起法见 `formulas.md`——反流量式只配天然小众题材，干货/里程碑类价值前置，配错比没钩子还伤）
- [ ] 核心钩子（大问题 + AI/趋势）有没有在 **40 秒内**抛出？超了＝红，砍前摇。
- [ ] 利益披露/背景是不是压成了**一句**？大段铺垫＝黄。
- [ ] 有没有一句**定调句**（"钉钉只是入口，不是主角"）？
> 开场是唯一不能返工的十秒——这段没过，别往下写。

## D3 · 逐字稿逻辑三维（仿 /dbs-script-flow）
- [ ] **过桥**：段与段之间有没有追问式过桥句？至少 3 处，且像现场想到、不像念标题。
- [ ] **扣环**：有没有一颗贯穿全片、每次含义加深的螺丝（"位置筛选人，位置也定义对错"）？——长稿限定、最多两次；**短干货稿不装扣环**，主线句说一次就走，重复＝车轱辘。
- [ ] **伏笔回收**：开头埋的比喻/概念（"城墙"），片尾有没有再用一次？
- [ ] **悬空引用**：有没有正文没铺垫过、却在收尾突然冒出来的口号/引用？有＝红，删掉或补铺垫。
- [ ] **理论落地**：理论段（科斯/单位经济学）讲完有没有立刻落到具体？悬空＝黄。

## D4 · AI 味扫描（仿 /dbs-ai-check，老徐口语版 · 最重要）
口播稿一旦有 AI 腔，人设就塌。逐条扫，**命中即改**：
- [ ] 有没有排比堆砌 / 三四个四字骈句连成串？口语里没人这么说话。
- [ ] 有没有**空形容词堆**：「前所未有的」「巨大的」「深刻的」「全方位的」？删掉不损失信息的形容词一律删，留下的要有数字或场景撑腰。
- [ ] 有没有**报幕腔 / 转场加戏**：说金句前先介绍金句（"今天会出现三次"）、"慢着""填坑"式转场表演？删掉，直接说、顺着讲。
- [ ] **同一个句式**（"是X不是Y"/对称句）出现三次以上？只留当重拳的那 1–2 记，其余改直说。
- [ ] 有没有书面过渡词：**"不仅…而且""值得注意的是""综上所述""总而言之""首先其次最后"**？→ 换成口语过桥。
- [ ] 每段是不是**等长**、太齐整？真人讲话长短不一，该有长句也有"就一句话"。
- [ ] 有没有**口语碎词**做呼吸：**"其实""说白了""你看""我跟你讲""说句公道话""问得好"**？一个都没有＝满屏 AI 味。
- [ ] 对观众是不是通篇「你 / 你们」？默认换**「咱 / 咱们」**坐到同一边，「你」省给直击位那一两处（照镜子句或收尾鼓励）。
- [ ] 金句是不是**太密**、句句想爆？密到没有喘息＝假。重拳一期 1–2 记就够，其余留白。
- [ ] 有没有**修辞比喻句**冒充人味（"换来的是一柜子吃灰的机器和一条没打磨的稿子"）？老徐的比喻是讲一段真故事（石英表 vs 机械表），句子里用大白话——人味靠流水账细节和自我暴露，不靠漂亮句子。
- [ ] 有没有**电报体断片**（"毛边，三样：""最后一关，最轻：设备"）？嘴说不出来的句子＝反向 AI 味。判据：大声读，嘴顺不顺。
- [ ] 结论对，但**不够"反直觉的具体"**？（AI 爱说正确的废话）——补一个具体到装备/数字/场景的落点。
- [ ] 有没有**留白拍**的设计（"说完停一拍"）？没有节奏标记＝像念稿。
> 判据一句话：**这段话，老徐会不会真的这么说出口？** 不会，就是 AI 写的。

**去味改写（去车轱辘话主力）→ 内置模块 `de-ai.md`**：D4 检测出 AI 味后，按 `references/de-ai.md` 去味改写。它专杀口播稿最大的 AI 味来源——**车轱辘话**，并守住一条铁律：**保留你的真金句、只删假排比和啰嗦**（一般的去味法会把金句也当 AI 腔删掉，这里反过来）。**已内置进本 skill**，不用再单独装去味工具。

## D5 · 传播力诊断（仿 /dbs-spread）
- [ ] 有没有 3–5 句**可单独截取**的金句（能当字幕卡/评论区置顶）？
- [ ] 全片有没有一个**立场记忆点**（一句话能被观众复述给别人）？
- [ ] 有没有**照镜子句**（"你在组织里窒息的那个瞬间…"直接看镜头）让观众代入？全片多用「咱」，这一两声「你」才扎得进去。
- [ ] 有没有给观众留**能接的话头**——替他喊出的问题、打赌式收尾（"三年后回来看这期"）、一个值得在评论区吵的点？评论是算法给量的硬通货。最强版＝**过招式**：拿全片框架出一道关于账号自己的题（"我在做的属于四类里的哪类？我究竟在卖什么？"——答案就是人设本身）。**行动型话头**也成立：「今天就掏出手机口喷一条试试，我期待你的作品」——把评论区升级成作品区。
- [ ] 结尾十秒是不是**最可能被截出去传播**的那段？（老徐的落点通常在双向祝福/行动号召）

---

## 总检 · 串联审稿 + 逐版修改记录
跑完 D1–D5，最后通读一遍：
- **车轱辘话**：同一个意思有没有在两段里各说一遍？合并。
- **空形容词**：把稿里的形容词逐个过一遍——删掉不损失信息的一律删，留下的要有数字或场景撑腰（金句不动，铁律见 `de-ai.md`）。
- **称呼**：数一遍「你」——除直击位（照镜子句 / 收尾鼓励）和引文，能换「咱」的都换（视角规矩见 `method.md`「创作视角」）。
- **首尾呼应**：收尾有没有回到开头那道题？
- **前摇/收尾长度**：前摇≤40 秒、收尾别复读全片（结论只说一次；「盘一下家底」式清单回顾也算复读）。
- **人设资产**：口头禅 / 签名 / 招牌句这期用得合身吗？签名类只属于特定内容，用过一次的口头禅别次次戴——固定资产是衣柜，不是制服（见 `persona.md`）。
- **四感终检（发布前最后四问）**：**别处听过吗**（新鲜感）/ **明天能用吗**（有用感）/ **看完有劲吗**（有希望感）/ **有话可接吗**（参与感）——答不上任何一问，回炉，而且能定位修哪里：**破立给新鲜、立用给有用、推合给希望**，缺哪感就回去修对应那几拍；**缺参与感修缝**——过桥句、照镜子句、收尾话头。标准见 `method.md`「四感及格线」。

每轮改动写进稿尾 **`## 附：逐版修改记录`**（`vN → vN+1` + 一句话改了什么）——这是老徐的定稿留痕，也是下次迭代的地图。范例见 `~/口播稿/钉钉置身事外_离职叙事_口播稿_v6.md` 文末。
