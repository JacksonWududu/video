# 自媒体起号方法论 · 老徐教学版

把老徐做自媒体验证过的一套打法，提炼成**学员能照着用的方法**。目标不是让学员模仿"老徐"这个人，是让他们学会**这套方法**，去做出**自己的**号。

## 这个 skill 教什么（也划清不教什么）

**教**：账号定位、选题体系、把话题写成站得住的内容（破立合）、单篇成稿格式、以及像老徐定稿那样的**五维诊断 + 串联审稿**。适合零基础起号、也适合有号但内容没起色的人做体检。

**老徐只是范例**：文档里凡出现老徐的人设/装备/签名，都是"一个定义清晰的账号长什么样"的**样板**，不是要你照抄。你的任务是套方法、填**你自己**的定位。

**不教/不做**：平台注册流程、买量投流、封面（走 guizang-cover）、图表（走 转转图表 那套）、配图（走 xiaoxu-illustrations）、公众号排版（走 wechat-article）。这个 skill 只管**定位 + 选题 + 内容 + 诊断**这条主线。

## 起号路线（学员照这个顺序走，一步都别跳）

### 第 0 课 · 底层心法：为什么有人关注你，并留下来（先讲这个）
先想明白"人凭什么关注你、凭什么留下来"再练招式：**勾 → 留 → 关注**三个动作、**让人占便宜**（你到底能分享什么）、**替身感 / 成长感**（为什么粉你这个人）、**活人感**（真实感受是护城河）、以及**起号前三篇**怎么打。这是"为什么"，后面五课是"怎么做"。见 `references/qihao-xinfa.md`。

### 第 1 课 · 定位你自己的账号
先想清「你是谁 × 给谁看 × 凭什么信你」。这一步没做完，后面全是无根之木。方法 + 老徐范例 + 学员自填工作表见 `references/persona.md`。

### 第 2 课 · 建选题体系 + 你自己的母题库
选题第一优先级是**实测题材**——「我拿真金白银替咱试了」（自然流量前三全是它；纯推演要靠逐点真案例撑，见文末标杆）。再学会把"人人都在吵的表层争论"往下挖成"底下那道真正的题"。选题/钩子/金句公式见 `references/formulas.md`；老徐的 **112 条母题原子库**（范例）见 `references/motifs-and-lines.md`，配套真稿例证 `references/cases.md`、机读版 `assets/atoms.jsonl`——学员照这套方法挖**自己领域**的母题库。

### 第 3 课 · 写一篇站得住的稿
三种骨架按题材选——**讲解 / 干货类**走「预判观众问题 → 回答 → 给解法」，**推演 / 解题类**立一道数字题当面解完（结尾拼成对号入座表），**评论类**走「破 → 立 → 用 → 推 → 合」（此形旗舰样例未发布无验证，前两种才是账号数据背书的主力）；底层都是"按观众的问题顺序往前走"。开场 40 秒内抛钩子，第一句起法看题材七选一（有自然播放背书的优先，反流量式是特定题材专用别当默认）。成稿过一条内容及格线——**四感**（新鲜感 / 有用感 / 有希望感 / 参与感）：前三感长在骨架上逐拍交付——**破立给新鲜、立用给有用、推合给希望**，参与感串在缝上（过桥句 / 照镜子句 / 收尾话头）；守三条语言铁律——**忌车轱辘话（句式复用也算）、忌过度形容词、忌报幕与弯弯绕**（动笔就守，别指望写完再洗）；创作视角**跟观众坐一边——多用「咱」、少用「你」**（「你」省给照镜子句那一两处）。方法读 `references/method.md`，成稿格式 + 空白模板见 `references/format.md` 和 `assets/template.md`。

### 第 4 课 · 五维诊断（这是老徐和野路子的分水岭）
写完不是完事，是**开始体检**。五个可单独调用的诊断——选题 / 开场钩子 / 逐字稿逻辑 / **AI 味扫描** / 传播力——见 `references/diagnostics.md`。学员也可以只拿一段来诊断（"帮我看看这个开头行不行"）。**去味改写（内置）**：D4 检测出 AI 味后，用内置模块 `references/de-ai.md` **去掉车轱辘话 / 空形容词 / AI 词汇**——它**改掉了通用去味工具里"删金句"这条会毁掉老徐风格的规则**（保留真金句、只杀假排比和啰嗦）。**已内置进本 skill**，不用再单独装。

### 第 5 课 · 串联审稿 + 迭代留痕
通查车轱辘话（含句式复用）、空形容词、报幕腔、称呼（你→咱）、过桥、首尾呼应、伏笔回收，发布前过**四感终检**（别处听过吗 / 明天能用吗 / 看完有劲吗 / 有话可接吗），改动写进「逐版修改记录」。见 `references/diagnostics.md` 末节。

### 第 6 课 · 起号运营（把一篇变成一个号）
选平台、定内容节奏、冷启动、留量漏斗、变现雏形——把方法接到"经营一个号"上。见 `references/qihao-path.md`。

### 红线（教学时先讲）
所有稿都守 `references/redlines.md`：批判结构不批判个人、对称分析、不消费旧关系、数字口径要标注。带学员时这条尤其重要——**帮他们躲开会翻车的坑**。

## 关于这个 skill

这套方法论是从老徐自己 30+ 篇口播稿里提炼、沉淀成的一个**自足 skill**——定位 / 选题 / 成稿 / 诊断 / 去味 全带上，学员只装这一个。里面的母题库、公式、五维诊断、去车轱辘话法，**料全部来自老徐本人的实践**，版权归老徐，随你发给学员、随你商用。

`钉钉置身事外_离职叙事_口播稿_v6.md` 是**工艺样例**：格式、逐版修改记录、串联审稿的示范最全，但**从未发布、无市场验证**——破立用推合深稿别当默认答案。带学员时拿爆款拆打法、拿钉钉拆格式——**看方法，不是抄老徐的话题和金句**。
