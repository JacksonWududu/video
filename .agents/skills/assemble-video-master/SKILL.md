## Shared-code preflight

Before creating or copying any episode-local script, read `leverage-video/src/shared/reuse-registry/registry.json`, inspect every registered shared module, and run `node leverage-video/src/shared/reuse-registry/create-reuse-decision.mjs <episode-workspace>`. The command fails if any episode-local script already exists; do not create a retroactive audit. In the generated `<episode-workspace>/schema/shared-reuse-decision-v1.json`, record exactly one `reuse`, `extend_shared`, or `not_applicable` decision with a concrete reason for every module. Run `node leverage-video/src/shared/reuse-registry/validate-reuse-decision.mjs <episode-workspace>/schema/shared-reuse-decision-v1.json --phase pre-script` and stop unless it passes. This binds the audit to the current registry, current module bytes, active episode, and empty pre-script inventory.

Reuse shared code when it already satisfies the contract. When reusable behavior is missing, add and test the minimum general implementation under `leverage-video/src/shared`, register it, rerun the complete reuse audit, and then consume it from the episode. Episode-local code may bind composition IDs, paths, locked assets, and episode configuration; it must not copy, fork, or reimplement shared behavior, validators, renderers, file-integrity logic, transition logic, media QA, or delivery locking.

After episode bindings exist, record each `reuse` or `extend_shared` consumer source path, checksum, and real shared import marker. Run the validator again with `--phase consumption` before any Remotion still, Studio, preview, render, or composition lock. Run the relevant shared and episode tests separately; do not encode a self-reported test result as trust evidence. A structurally complete pre-script decision without verified source consumption is not render authorization. The shared assembly-plan builder must read this exact decision file, verify its checksum, and rerun consumption validation; plan input may not self-report `result: pass`.

For an episode whose non-empty script directory demonstrably predates this gate, stop unless the user gives explicit user authorization for a one-time migration of that exact episode. Then run `create-legacy-reuse-decision.mjs`, record the full existing script inventory and checksums plus the exact authorization message/time, and require `--phase legacy-migration`. Do not move or clear the script directory, do not fabricate an empty `pre_script_inventory`, and do not describe the migration as a pre-script audit. Preserve every baseline script byte; list only newly added binding files in `legacy_additions`, attach their current checksums and real shared imports, and require `--phase consumption` before rendering. Any baseline mutation or undeclared addition is a blocker.

## Preconditions

- The exact script, validated narration master, audio-timed storyboard, and active asset manifest are locked.
- Immediately before assembly, rerun `validate_visual_approval_state.py validate-locked` against the active episode state and repository root; require a passing `visual-assets-lock-verification-v1` whose current disk checksum map equals the locked visual manifest.
- The active `per-shot-visual-direction-review-v3` evidence is approved and bound to storyboard/manifest, including machine scene class, white-cat, active route, visual language, route-resolved final visible-text fields, and the exact source path for `local-video-file`. `comic-imagegen` and `doodle-slides` are forbidden in new, modified, revoice, preview, Studio, composition-lock, and render work; unchanged completed legacy evidence remains readable only. White-cat `imagegen`, every `xuan-paper-diorama`, and every local-video shot must be text-free and title-free. 宣纸与墨线知识卡 assets must match their route-catalog-pinned Skill/profile fingerprints. Local video must carry strict exact-byte approval plus a current `local-video-match-v1` binding. Other active routes retain their own text contracts. Missing, pending, incompatible, stale, or mismatched evidence blocks.
- Require `visual_direction_artifact_policy`: current work is `current_v3`; v1/v2 may enter only as unchanged completed `legacy_read_only` evidence with no modified shot IDs. A reopened legacy shot must supply v3 before still, preview, Studio, composition lock, or render.
- Require checksum-current `storyboard-visual-rhythm-v2` and `action-state-schedule-v4` for new work, bound to the same density selection SHA-256 and canonical counts/fallback/split fields. Standard counts remain unchanged; rich uses its 2–6 stateful and 4–13-pose hard ranges. Verify complete UTF-8 coverage, unique semantics, `15 × N + transition frames`, background exclusion, and exactly `pose_count - 1` intra-shot transitions. Legacy v1/v3 remains read-only.
- Require valid workflow selection evidence. Manual preserves its existing lock/composition/caption order. One-click requires final complete exact-list approval and an explicit caption choice before still, Studio, preview, composition, or render.
- Every active visual and normalized opening cover have measured per-file 1920×1080 evidence. For Ian this includes the opaque background, every transparent semantic layer, and final composite plus deterministic recomposition evidence. Every still, preview, contact sheet, and render target uses the native `16:9`, `1920×1080` landscape canvas.
- Every data scene, transition asset, and shared opening-cover archive/normalized raster has passed its own QA.
- Every ordinary boundary has a structured `scene-transition-v3` decision with valid semantic class, source/next routes, recomputed route-first or shared-fallback recommendation authority/rule ID, selected registered kind/options, renderer, and approval hash. `cut` requires zero seconds/frames and empty options; visible effects require 0.3–0.6 seconds. Missing, `none`, wrong renderer, or unresolved evidence blocks.
- The exact first-sentence timing evidence has passed narration QA, and the assembly plan declares `direct-first-shot-v1` with `S01` plus narration at frame 0. Publishing-cover artifacts, when present, are outside the composition fingerprint.
- The active episode has either a passing pre-script `shared-reuse-decision-v1.json`, or a passing explicitly authorized one-time legacy migration with a complete baseline inventory and unchanged baseline bytes.

For `revoice_variant`, the standard active-manifest narration fingerprint may remain bound to the parent. Require instead the immutable parent visual manifest plus a passing `revoice-visual-binding` that records the approved retiming-only storyboard, replacement narration master, exact locked visual sequence, prior per-image approvals, unchanged approved white-cat/route map, and unchanged canvas/cover/opening evidence.

## Automatic sound design

- After visual lock and before creating the shared-reuse decision or any episode script, analyze every locked storyboard shot and its action states, Ian entries, Whiteboard timing segments, intra/inter-shot transitions, and visible local-video actions. Run `prepare-sound-design.mjs` to write one episode-local `knowledge-video-sound-design-v1` under `schema/`, bound to the storyboard, narration master, visual manifest, rhythm/action map, transition review, and active shared-library path/checksum.
- Record every candidate event as `audible` or `silent` with a concrete reason. Do not sonify ordinary cuts, abstract narration, or nouns without a visible event. Limit non-Ian shots to two cues, keep strong cues 30 frames apart, and drop a generic cue within 12 frames of an Ian cue. Every audible cue binds one semantic role, exact frame, intensity, render owner, immutable source, pre-trimmed episode WAV, gain, and QA.
- Reuse `shared-sound-effect-library-v2` first. If an audible role is absent, announce the needed sound and purpose, live-verify the official item and license, prefer Mixkit and use Pixabay only as fallback, then run the shared acquisition tool. Accept only cross-platform commercial/no-attribution sources. Publish a new immutable library revision, clean the exact task-created temporary directory on every exit, rebuild sound design, and only then create the reuse decision. Any uncertain license, unavailable page, unsupported host/media, or acquisition failure blocks assembly; never substitute an approximate cue.
- No additional user approval is required. Revoice bypasses analysis/acquisition and preserves every parent sound identity, trim, gain, and semantic reason; only exact cue frames may be retimed.

## Assemble a revoice variant

- Consume the replacement narration master and approved retiming-only storyboard as timing authority while loading visual assets only from the parent manifest and `revoice-visual-binding`.
- Preserve the locked visual sequence, state IDs/semantics/byte ranges/order/assets/camera, every intra-shot effect, and parent direction/inter-shot evidence. A parent using retired `comic-imagegen` cannot enter revoice. Recompute only real-audio shot/boundary and state entry/end frames; revoice never recomputes state count/order or any inter-shot transition kind/options/duration/frame count. Block when any effect changes or a target cannot retain at least 15 clean frames, or a shot is shorter than its locked transition; never delete a state or substitute an effect. Historical v2 keeps its old 18–75/mandatory-watercolor limits.
- Recompute the cover hold from the replacement first-sentence end frame and bind all later shots, existing state occurrences, and sound-effect cues to the new real-audio schedule while preserving each transition length exactly.
- Do not invoke image generation, change an image, rewrite the parent visual manifest, or reuse the old encoded master with an audio swap. Build and QA a new source-derived composition, per-topic opening, contact sheet, and final master.
- Preserve the parent BGM mode. Disabled remains free of BGM access. Enabled reuses only the already archived checksum-matching source and the same mix policy after the new duration lock.

## Assemble the BGM-free base

1. Apply `direct-first-shot-v1`: start both `S01` and the validated narration master at composition frame 0. Do not import a publishing cover, mount `EpisodeOpening`, create `OPEN-00`, or add any other pre-roll.
2. Bind every shot directly to its exact narration-master in/out time, plus its accepted asset/state family, state schedule, crop, transition, approved route-owned on-screen-text intent, and sound-effect cues. Do not accept a generic top-title or timeline text-overlay field.
   - Reuse `leverage-video/src/shared/scene-transitions`; every outgoing non-terminal shot must execute its exact user-selected registered kind and options without fallback, normalization, or substitution and without changing locked shot/audio frames or total duration.
   - Only the final clean hold may omit an outgoing transition.
3. Enforce the active v4 schedule (or unchanged legacy v3) and exact `intra-shot-transition-v1` map. `IntraShotImageSequence` executes zero-frame `cut` or exactly authorized 18-frame `watercolor-bloom` without adding shot duration or fallback. One-image shots have zero entries; Whiteboard/local video keep their approved MP4 contracts.
4. Keep paired exact `source_text`, punctuation-free `display_text`, and narration-derived cue timing locked. Do not mount a caption component in the caption-neutral base. For every active `visual_generation_route: ian-handdrawn-ppt`, require a checksum-current `ian-knowledge-video-layered-scene-v2` package and exact `ian-layered-scene-plan-v1`. Revalidate master lineage, deterministic package derivation, text containment, final recomposition, and visual-rhythm projection. New or revised assembly also requires `ian-layered-entry-effects-v2`, its fixed policy SHA, current shared SFX manifest SHA, exact layer/map checksum, public SVG/WAV bytes, and class consistency. Render only approved background/final layers. Per layer, allow deterministic 8-frame `soft-settle-v1`, 12-frame SVG-bound `ink-draw-reveal-v1`, or reasoned `fade-only-v1`; use at most two motion language families per shot. Give exact-frame pre-trimmed SFX only to 2–3 key layers in a multi-layer shot; leave other entries silent, cap one source at two uses per shot, require different adjacent audible timbres and semantic selection reasons, and forbid pitch/speed-only pseudo-variation. Keep narration gain 1, disable normalization, and lower only the SFX bus if final peak exceeds -1 dBFS. Forbid whole-scene motion, scaling, rotation, randomness, inferred raster tracing, unapproved masks/crops, parallax, internal cuts, inferred timing, and label recreation.
5. Under `explicit-visual-generation-route-v3`, route `imagegen` and `xuan-paper-diorama` to `NarrativeScene`, Ian to `IanLayeredScene`, `ink-doodle-knowledge-card` to `GraphicScene`, Whiteboard to `WhiteboardScene`, and `local-video-file` to `LocalVideoScene`; reject `comic-imagegen` and `doodle-slides`. Local video uses the exact archived 1920×1080 H.264 bytes with matched playback, muted source audio, and no trim/loop/pad/interpolation/crop/stretch/redraw/text overlay. 宣纸与墨线知识卡 consume only exact-byte-approved PNGs; Remotion must not simulate either style. `S01` begins at frame 0; every later Ian scene entry remains owned only by the approved incoming `scene-transition-v3`. Multiple Ink states execute their approved generic map, normally direct cuts. `TransitionedScene` preserves separate inter-shot behavior.
6. Assemble narration, accepted visuals, state families, Ian layered scenes, raster data/logic visuals, transitions, approved route-owned raster/annotation text, and only sound effects listed with passing QA in the active sound-effect manifest. Add, rewrite, reposition, or remove no title/text overlay; add no opening-source audio, subtitle stream, unlisted sound effect, BGM, or arbitrary tail padding.
   - Current work requires `knowledge-video-assembly-plan-v3`. Render `global_sound_effect_track_v1` cues through shared `SoundEffectTrack`; keep `ian_layered_scene` cues inside `IanLayeredScene`. Require exact one-owner coverage and apply the same `bus_gain_multiplier` to both. `knowledge-video-assembly-plan-v2` remains completed legacy read-only.

## Preflight and lock duration

- Build through `leverage-video/src/shared/assembly-plan`, which validates sound design, visual-direction and visual-rhythm approvals, motion tiers, explicit routes, exact asset-route equality, v3 state schedules, shared reuse, and both transition layers. Before any Remotion still, Studio, preview, render, or composition lock, require `node .agents/skills/assemble-video-master/scripts/validate-sound-design.mjs <assembly-plan.json> <composition-source.tsx>`, `validate-intra-shot-transitions.mjs`, and `validate-scene-transitions.mjs` to pass. The transition validator still dispatches legacy contracts; v2 assembly plans remain readable only for completed unchanged history.
- Resolve an existing supported Chrome-family executable and pass its absolute path explicitly to every Remotion still, Studio, and render command.
- Never run a bare command that could download Chrome Headless Shell.
- Validate one still and visually inspect it before any full render.
- Inspect S01 at frame 0, the complete first-sentence S01 interval, first-sentence A/V sync, every action state and boundary, every ordinary transition's first/middle/final frame, every scene's representative frames, every data reveal, approved on-screen text, framing, registration, flicker, unintended black frames, hold timing, and the reserved bottom-caption safe area. Verify that no publishing-cover raster or `OPEN-00` appears in the master.
- Repair failures and repeat until the BGM-free base passes; then record `composition_lock` with the BGM-free input fingerprint/checksum, exact duration, QA result, and lock time.

## Require the final caption choice

- Manual asks after `composition_lock`. One-click asks immediately after final visual exact-list approval, and no protected Remotion action may occur before the explicit choice. Present exactly `1. 无字幕；2. 有字幕；3. 有字幕跟无字幕的视频都有`.
- Record `caption_delivery.mode` as `caption_free_only`, `captioned_only`, or `both`, with the user's exact message/time and mechanically derived `required_delivery_roles` plus `required_internal_qa_roles`.
- Render captioned roles with exactly one versioned caption component using only the locked punctuation-free `display_text` and narration-master cue timing. Render caption-free roles with that component absent.
- Keep zero subtitle streams and no subtitle sidecars in every mode. In `both`, all non-caption inputs, frame schedules, audio, BGM mode, visual order, and opening sources must be identical; only the caption layer may differ.

## Resolve audio mode, render, verify, and deliver

- Set `bgm.mode` to `disabled` when it is missing or unspecified. In this default mode, do not read the shared BGM selector, inspect or copy any BGM file, create a BGM track, or ask the user whether to enable it. Render with narration and only manifest-listed, QA-passing discrete sound effects.
- Use `enabled` only when the active episode state records complete current-episode enablement and composition-lock evidence. If either is missing or inconsistent, stop before any BGM access. Then follow the final-mix reference to resolve and validate the selected BGM and mix it as a separate narration-subordinate track.
- Render only the full masters in `required_delivery_roles` and their matching first-shot prefixes in `required_internal_qa_roles`, each as a 1920×1080, 16:9 landscape, 30 fps H.264 MP4. Each prefix is rendered from the exact same composition and inputs used at frame zero, then compared to its same-caption-role master by decoded frames. It contains S01 and is internal QA evidence only; never embed the encoded prefix into the master.
- Decode and measure every generated still and contact-sheet raster; probe and fully decode every selected preview and final file. Run `validate-render-sound-mix.mjs <assembly-plan.json> <render.mp4>` for each current output. Verify exact dimensions, codecs, duration, A/V sync, black frames, representative playback, cover QA, role-appropriate contact-sheet evidence, zero subtitle streams, and role-appropriate burned-in-caption presence or absence. Verify that every included sound effect matches the active sound-effect manifest with no unlisted effect. In disabled mode, verify provenance shows no BGM input or track; in enabled mode, verify BGM coverage, narration dominance, and the recorded mix input fingerprints.
- Create an active delivery transaction manifest under the episode workspace's `schema/`, then copy only QA-approved full masters in `required_delivery_roles` to the fixed delivery directory with distinct new versioned filenames. Never copy an opening role or include it in that manifest. Compare sizes and checksums, probe and decode every delivered copy, and require the transaction manifest's role set to match `required_delivery_roles` exactly. Never use the shared directory's full listing as the role set or delete unrelated/historical deliveries. Return links to the selected complete full video or videos, the cover, narration master, and contact-sheet evidence; do not return the standalone opening.
- For a revoice variant, include the `variant_id` and caption role in every new filename, return the replacement narration master, require a fresh caption choice, and leave every parent render and delivery unchanged.
